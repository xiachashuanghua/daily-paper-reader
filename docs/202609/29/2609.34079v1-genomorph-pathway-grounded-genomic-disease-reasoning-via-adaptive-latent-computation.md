## 摘要
大语言模型（LLM）在生物推理方面已展现出强大能力；然而，基因组疾病推断在很大程度上仍依赖于记忆的基因-疾病关联，而非对生物学通路的理解。这种捷径学习削弱了鲁棒性与泛化能力，并在分子标识符不可用时失效。我们提出 GenoMorph，一个多模态基因组推理框架，将疾病预测从联想式基因-疾病映射转向基于通路的推理。GenoMorph 将冻结的 DNA 基础模型与问题条件化的交叉注意力融合、自适应潜在推理（LatentSp）、用于迭代式基因组证据重注入的残差推理门控，以及由层次化最优传输（OT）正则化的拒绝采样微调相结合。GenoMorph 并不学习直接的基因-疾病映射，而是将基因组序列表示与潜在通路动态对齐，使推理轨迹在给出疾病预测之前遵循分子相互作用。LatentSp 根据推理置信度动态分配计算量，减少不必要的推理步骤并提升推理效率。我们进一步基于京都基因与基因组百科全书（KEGG）构建了一个匿名化基准，将每个基因和分子标识符替换为匿名符号，同时保留序列与通路拓扑结构，从而消除记忆捷径。GenoMorph 将加权 F1 从 0.7863（BioReason）提升至 0.9412，而结合自适应潜在推理的拒绝采样微调将其进一步提升至 0.9725，同时将延迟降低近 60%。在匿名化基准上，其 F1 达到 0.9465，显著优于先前系统，证实准确的疾病预测可以源自通路推理，而非记忆的基因-疾病关联。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in biological reasoning; however, genomic disease inference remains largely dependent on memorized gene-disease associations rather than understanding biological pathways. This shortcut learning undermines robustness and generalization, and breaks down when molecular identifiers are unavailable. We present GenoMorph, a multimodal genomic reasoning framework that shifts disease prediction from associative gene-disease mapping toward pathway-grounded reasoning. GenoMorph couples a frozen DNA foundation model with question-conditioned cross-attention fusion, self-adaptive latent reasoning (LatentSp), a residual reasoning gate for iterative genomic evidence reinjection, and rejection sampling fine-tuning regularized by hierarchical optimal transport (OT). Rather than learning direct gene-disease mappings, GenoMorph aligns genomic sequence representations with latent pathway dynamics, enabling reasoning trajectories that follow molecular interactions before producing disease predictions. LatentSp dynamically allocates computation according to reasoning confidence, reducing unnecessary reasoning steps and improving inference efficiency. We further construct an anonymized benchmark from the Kyoto Encyclopedia of Genes and Genomes (KEGG), replacing every gene and molecular identifier with anonymous symbols while preserving sequences and pathway topology, thereby removing memorization shortcuts. GenoMorph raises the weighted F1 from 0.7863 (BioReason) to 0.9412, and rejection sampling fine-tuning with self-adaptive latent reasoning pushes it to 0.9725 while cutting latency nearly 60%. On the anonymized benchmark it reaches 0.9465 F1, substantially outperforming prior systems and confirming that accurate disease prediction can arise from pathway reasoning rather than memorized gene-disease associations.

## 1. 核心问题与研究背景

- **研究动机**：当前基于大语言模型（LLM）的基因组疾病推断，本质上依赖**记忆的基因–疾病关联**，而非对生物学通路的理解。这种"捷径学习"（shortcut learning）带来三大问题：
  - 鲁棒性差、泛化能力弱；
  - 当基因/分子标识符被替换或不可见（新基因、别名、匿名化临床数据）时，预测完全失效；
  - 在高风险医疗场景中，幻觉与无依据预测会损害可信度。
- **现有方案的局限**：无论是 BioReason（静态线性投影融合 DNA 与文本）、GeneGPT（调用 NCBI API），还是 TxGemma（通用机制推理），都依赖**静态投影层、上下文 API 调用或监督微调**，无法实现基因组证据与语言推理之间的动态交互。疾病预测退化为"基因身份 → 疾病标签"的联想映射。
- **整体含义**：论文将任务重新定义为**通路驱动的机制推理**（pathway-grounded reasoning），提出核心命题——"疾病预测应源于对连接序列变异与表型的生物学通路的推理，而非记忆的基因身份"。若模型真正学会通路推理，则在基因名被完全匿名化后仍应保持性能。

## 2. 方法论

### 2.1 核心思想

GenoMorph 是一个**多模态基因组推理框架**，将 DNA 序列与生物医学问题通过问题条件化融合，并通过**潜在空间推理 + 几何感知优化 + 自适应计算**，学习"沿通路动态推理"而非直接映射。

### 2.2 关键技术组件（四阶段训练流程）

**Stage 1：监督微调（SFT）**，包含三个组件：

- **CrossAttentionFusion（问题条件化基因组对齐）**
  - 以冻结 Evo2-7B 的 DNA 表示 `H_DNA` 作为 Query，以 Qwen3 的问题嵌入 `H_Q` 作为 Key/Value；
  - `A = softmax(QK^T / √d_h)`，8 个注意力头，掩蔽 padding；
  - `H'_DNA = W_O(AV)`，再投影到 LLM 隐空间并插入 `<|dna pad|>` 占位符；
  - 与 BioReason 的静态线性投影相比，使基因组表示成为**问题的函数**，可有选择地强调与当前问题相关的序列证据。

- **LatentSp（课程式潜在推理）**
  - 计算每个 token 的预测熵 `H_t`，及每个推理步的平均熵 `H_step^(k)`；
  - 将低熵（高置信）推理步逐步替换为 `<start-latent> ... <end-latent>` 潜占位符（保持原长度），课程式地逐步增加替换比例；
  - 仅在可见 token 集合 Ω 上计算自回归损失 `L_LatentSp = -Σ log P(y_t | x, ỹ_<t)`，迫使模型在省略中间 token 时仍保持推理一致性。

- **ThinkingResidualGate（基因组证据重注入）**
  - 对 token 嵌入 `E` 计算两个门：`r = σ(W_r E)`（残差保持）、`i = σ(W_i E)`（基因组注入）；
  - 残差系数 `a = r_min + (r_max − r_min)σ(λ + r)`，其中 `r_min=0.5, r_max=0.99`；
  - 门控表示 `Ẽ = aE + √(1−a²+ε)(i ⊙ R)`，其中 `R` 为广播后的序列级基因组表示；
  - 作用：在推理推进过程中**按需重注入基因组证据**，而不覆盖语言上下文。

**Stage 2：离线层次化最优传输（HiRef-OT）**

- 冻结 Stage-1 模型，对每个样本分别对 DNA 融合输出与答案 token 做均值池化并 ℓ2 归一化，形成基因组流形 X 与答案流形 Y；
- 以 `C_ij = ||û_DNA_i − û_Ans_j||²` 为传输代价，用 HiRef 递归分解求解 Monge 对应 `T*`；
- **固定的是目标几何**（答案嵌入与每样本目标分配），而非距离本身；训练时基因组表示在移动，故 OT 距离 `d_OT^(i)` 每步实时重算，作为几何感知奖励信号。

**Stage 3：GRPO 多目标强化优化**

- 对每个输入采样 G 条轨迹，使用**八项加权奖励**：
  - `R = 0.5 R_format + 2.0 R_correct + 0.5 R_compqual + 0.3 R_reasqual + 0.5 R_latentfmt + 0.5 R_OT + 0.75 R_latent + 0.5 R_concise`
  - 分别对应结构格式、预测正确性（权重最大）、完成质量、推理多样性、潜块格式合法性、HiRef 几何一致性、潜计算效率、简洁性；
- 组相对优势 `A_i = R(y_i) − (1/G)ΣR(y_j)`，使用 PPO 风格的裁剪 + KL 正则目标（ε=0.1，β=0.05）；
- **自适应潜在计算**：潜推理阈值 `θ_low` 不采用固定调度或 REINFORCE（论文指出 GRPO 组内优势零均值、决策组内共享，导致无信用信号），而是用**无导数的滑动窗口搜索**在线更新（扰动 ±δ，用有限差分对窗口化奖励基线估计梯度）。

**Stage 4：拒绝采样微调（RSFT）**

- GRPO 收敛后为每个输入采样多条候选轨迹；
- **两步筛选（非标量奖励阈值）**：
  1. **硬门控**：仅保留预测正确且格式合法（解析出有效推理结构与非空答案）的轨迹；
  2. **幸存者偏好**：优先选择使用潜在推理的轨迹，平局时取最短完成长度（或最低生成时间）；
  - 即 `y*(x) = arg max_{ok(y)=1} (lat(y), −len(y))`，字典序选择；
- 在接受的轨迹上做标准监督微调 `L_RSFT = −Σ log P_θ(y_t | x, y_<t)`，**将自适应策略内化到参数中**，推理时无需在线熵估计或手工阈值。

### 2.3 问题形式化

- 要求满足两个条件：
  - `P_pred(f)`：从 `(S, Q)` 正确推断疾病 y*；
  - `P_mech(f)`：`f(S, Q) = f(S, A(Q))`，其中 A 是对所有基因/分子实体的全局双射重命名，即预测应对标识符匿名化**保持不变**；
- 通路图 G=(V,E) 仅在训练时作为几何监督使用，推理时从不提供。

- **性能大幅提升**：GenoMorph 将 Weighted-F1 从 BioReason 的 0.7863 提升至 0.9412（GRPO），RSFT 后进一步达 **0.9725**；准确率从 0.9069（BioReason SFT）升至 0.9552 / 0.9759。

  - LLM-only（Qwen3）准确率暴跌 39.66 个百分点，保留率仅 55.4%；
  - BioReason SFT 保留 66.5%；

- **消融关键发现**：

  - 学习型 θ_low 显著优于固定阈值：匿名准确率从 74.59%（θ_low=3）提升至 92.07%；
  - LatentSp 使延迟降低超 65% 同时提升精度；
  - Gate 在 SFT 阶段将 Named 准确率推至 98.28%。
- **错误性质**：13 个剩余错误中约 54%（7/13）源于**疾病命名粒度差异**（如将 CJD 预测为上位概念"朊病毒病"），仅 6 个为真实分类错误——说明严格精确匹配评测可能低估了真实推理能力。
- **总体论断**：疾病预测可源自**通路推理**而非记忆的基因–疾病关联；自适应潜在推理能同时优化推理质量与计算效率。

## 7. 优点（方法/实验亮点）

- **问题重构具有认识论深度**：将基因组疾病推理的缺陷诊断为"认识论"而非"架构"问题，并用可证伪的匿名化实验直接检验——设计巧妙且论证有力。
- **匿名化基准是核心创新**：全局一致的双射重命名保留序列与通路拓扑，剥离词汇捷径，是检验"机制推理 vs 身份记忆"的干净探针，可复用为社区基准。
- **问题条件化融合**：相比静态线性投影，CrossAttentionFusion 使基因组表示随问题自适应，机制上更合理。
- **自适应潜在计算设计务实**：
  - LatentSp 课程式迁移高置信推理到潜空间；
  - 明确指出 REINFORCE 在此场景失效的原因（组内优势零均值 + 决策组内共享），改用无导数滑动窗口搜索——这是一个有洞察力的工程判断。
- **RSFT 的两步字典序筛选**：硬门控 + 偏好选择（先正确合法、再偏好潜推理、再偏好最短），避免标量奖励阈值的脆弱性，且将自适应策略内化，**推理时无需在线熵估计**，工程可落地性强。
- **精度–效率双赢**：与多数"提升精度必增延迟"的工作不同，最终模型同时占据 Pareto 前沿的最佳点。
- **错误分析诚实**：主动区分"命名粒度错误"与"真实推理错误"，并对评测指标本身提出反思（建议本体感知评测）。

## 8. 不足与局限

- **数据与场景覆盖有限**：
  - 仅在单一 KEGG 衍生基准上评测，缺少临床基因组数据集（如 ClinVar、TCGA、真实电子病历）验证；
  - 数据集规模、样本数、类别分布均未在文中明确给出；
  - 任务被限定为"从 DNA + 问题预测疾病名"，未涉及变异致病性分级、药物响应等更复杂临床任务。
- **架构单一**：仅使用单一基因组编码器（Evo2-7B），未探索其他 DNA 基础模型、联合优化编码器或 NAS 架构搜索。
- **评测协议偏差风险**：
  - 疾病名归一化后仍采用严格精确匹配，可能系统性低估（论文自认约

  - 零样本生物医学基线的近乎零性能，可能部分源于提示词/协议不匹配，而非模型能力本身，削弱了对比的说服力。
- **统计严谨性欠缺**：
  - 未报告多次随机种子运行的均值±标准差，也无显著性检验（如配对 bootstrap 或 t 检验），单一 seed=23 的结果可能受初始化与采样噪声影响；
  - GRPO 与 RSFT 涉及大量采样，方差控制尤为关键，但文中未提供置信区间。
- **奖励工程的黑箱性**：
  - 八项奖励权重（0.5/2.0/0.5/0.3/0.5/0.5/0.75/0.5）缺乏消融或敏感性分析，无法判断性能对权重扰动的稳健性；
  - `R_compqual`、`R_reasqual` 等"质量"类奖励的具体定义与判定方式（是否用 LLM 裁判、是否引入额外偏见）在总结层面尚不清晰，存在引入评审模型偏好的风险。
- **阈值搜索的可扩展性**：Stage 3 的滑动窗口无导数搜索虽避开了 REINFORCE 的信用分配问题，但每次扰动都需重新评估奖励基线，随训练规模扩大的计算开销与收敛性缺乏理论保证。
- **潜推理的可解释性代价**：将高置信推理步替换为潜占位符，虽提升了效率，但中间推理轨迹变得不可读，与医疗场景对"可审计推理链"的需求存在潜在张力；论文未讨论如何在潜推理与可解释性之间权衡。
- **通路监督的隐式性**：通路图仅作为离线 OT 的几何目标间接使用，未显式建模通路中的节点/边关系（如基因–基因相互作用、上下游方向性），"通路驱动"的宣称与实际的几何对齐之间存在语义鸿沟——OT 对齐的是嵌入空间距离，未必等价于生物学通路推理。
- **匿名化基准的边界**：
  - 双射重命名只剥离了**词汇**捷径，但若模型仍依赖序列统计特征与答案分布的共现，匿名化未必能完全排除"记忆"，需辅以序列打乱/置换等对照实验；
  - 匿名符号（gene 1, gene 2…）本身可能携带隐式顺序信息，若映射非随机化则可能残留捷径。

## 9. 综合评述与定位

- **理论贡献层面**：论文最有价值的不是某个模块，而是**将评测本身武器化**——匿名化基准把"模型是否真在推理"这一哲学问题转化为可量化的 ΔAccuracy 指标，为后续工作提供了可复用的检验范式。
- **方法贡献层面**：CrossAttentionFusion（问题条件化）、LatentSp（课程式潜推理）、HiRef-OT（几何监督）、自适应阈值搜索、RSFT（策略内化）构成一条完整的"融合→压缩→对齐→优化→固化"技术链，各组件动机清晰、衔接自然。
- **工程贡献层面**：离线预计算 DNA 表示、推理时免除在线熵估计、精度与延迟同时优化的 Pareto 表现，使其在资源受限的落地场景中具备实际吸引力。
- **相对现有工作的位置**：相较 BioReason 的静态融合与 GeneGPT 的 API 检索，GenoMorph 首次将"基因组–语言"交互从**输入端**推进到**推理过程内部**，并用强化学习与几何约束塑造推理路径，属于该方向的方法学进阶。
- **尚待回答的关键问题**：
  - 当面对**训练分布外**的真实致病变异（非 KEGG 已知基因）时，通路推理能否真正泛化？
  - 匿名化下的高保留率，究竟是"机制推理"还是"序列–表型统计映射"的另一种形式？
  - 在临床级噪声数据（测序错误、不完整表型）下，框架的鲁棒性如何？

## 10. 可复现性与开放性问题

- **可复现性有利因素**：数据基于公开 KEGG 衍生语料，骨干模型（Evo2-7B、Qwen3-1.7B）与超参配置（学习率、LoRA 秩、批大小、熵阈值）均有明确报告，随机种子给定，理论上具备复现基础。
- **可复现性不利因素**：训练数据具体样本数与划分比例未披露；八项奖励中的"质量"类打分规则不明；HiRef-OT 的递归分解实现细节（层级数、终止条件）未展开；GPU 数量与总训练时长缺失，使算力成本难以评估。
- **开放方向**：
  - 将匿名化基准扩展为多数据集、多模态（含蛋白结构、表达谱）的标准压力测试；
  - 引入本体层次化评测，区分"粒度错误"与"真实错误"；
  - 探索显式通路图神经网络与 OT 几何对齐的结合，弥合语义鸿沟；
  - 研究潜推理的可解释化（如潜占位符的事后解码或归因）。

---

**总体结论**：GenoMorph 通过问题条件化融合、课程式潜推理、几何感知强化优化与自适应策略固化，在 KEGG 疾病预测任务上同时实现了**精度跃升**（Weighted-F1 0.9725）与**延迟大幅压缩**（约 9.75 s），并以匿名化基准有力论证了"通路推理优于身份记忆"的核心命题。其主要短板在于评测数据集单一、统计严谨性与奖励设计透明度不足、通路语义与 OT 几何之间的理论衔接尚显薄弱。总体而言，这是一项**问题意识锐利、方法体系完整、工程落地性强**的工作，其匿名化评测范式与自适应潜在推理机制具有较高的借鉴与推广价值。
