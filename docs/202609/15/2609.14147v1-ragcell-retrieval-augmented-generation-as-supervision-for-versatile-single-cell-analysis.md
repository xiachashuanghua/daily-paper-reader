## 摘要
单细胞基础模型（scFMs）通过为通用单细胞分析提供可泛化、任务无关的表示，正在改变计算生物学。尽管它们在促进下游任务快速部署方面取得了进展，但现成的 scFMs 仍存在一些被忽视的问题：（I）（预训练成本。）基于预训练的 scFMs 需要在大规模细胞上进行预训练，导致其在应用中耗费大量资源。（II）（异质性鸿沟。）基于大语言模型（LLM）的 scFMs 忽略了 LLM 文本空间与原始细胞空间之间巨大的异质性鸿沟，导致面对下游任务时能力不足。为此，我们提出 RAGCell，一个在成本效益和高性能上实现双赢的通用单细胞分析框架。RAGCell 的成功在于两个关键方面：利用 LLM 构建细胞级和特征级知识数据库，将其作为训练细胞模型的监督信号，并显著降低训练成本（优于基于预训练的 scFMs）。将细胞表示与来自双层知识数据库的文本嵌入对齐，实现从文本空间到细胞空间的知识迁移，并有效缓解异质性鸿沟（优于基于 LLM 的 scFMs）。通过在六个下游单细胞分析任务上的大量实验，我们证明 RAGCell 与最先进的 scFMs 相比取得了出色性能，同时运行成本不到基于预训练的 scFMs 的约 1/10。

## Abstract
Single-cell foundation models (scFMs) are transforming computational biology by enabling generalizable, task-agnostic representations for versatile single-cell analysis. Despite their progress in facilitating rapid deployment for downstream tasks, off-the-shelf scFMs still have some overlooked concerns: (I) (Pretraining Cost.) Pretrain-based scFMs necessitate pretraining on a vast volume of cells, rendering it draining resources in applications. (II) (Heterogeneous Gap.) Large Language Models (LLM)-based scFMs ignore the tremendous heterogeneous gap between LLM textual and raw cellular spaces, leading to insufficient capability when facing downstream tasks.   To this end, we introduce RAGCell, a versatile single-cell analysis framework that achieves a double-win in both cost-effectiveness and high performance. The success of RAGCell lies in two key aspects: Leveraging LLMs to construct cell-level and feature-level knowledge databases, which serve as supervision signals for training the cell model and significantly reduce the training cost ($>$pretrain-based scFMs). Aligning cell representations with text embeddings from the bi-level knowledge databases, enabling knowledge transfer from textual spaces to cellular spaces and effectively mitigating the heterogeneous gap ($>$LLM-based scFMs). Through extensive experiments on six downstream single-cell analysis tasks, we demonstrate that RAGCell achieves outstanding performance compared to state-of-the-art scFMs while operating at less than $\sim$1/10 the cost of pretrain-based scFMs.

### 1.1 背景

  - **基于 LLM 的 scFMs**：如 GenePT、scELMo，直接用 LLM 生成的嵌入构造细胞表示。

### 1.2 两大被忽视的痛点
- **（I）预训练成本高**：预训练型 scFMs 需在百万至数千万细胞上训练，耗时耗资源；且常需人工专家定义基因词表（gene vocabulary）做 tokenization，获取专家先验困难、劳动密集，进一步降低训练效率。
- **（II）异质性鸿沟（Heterogeneous Gap）**：LLM 文本空间由自然语言预训练构建，细胞空间用于建模生物数据，二者存在本质性巨大差异。基于 LLM 的 scFMs 虽成本低，但忽视该鸿沟，下游任务（尤其微调场景）性能不足。

### 1.3 研究目标
- 提出 **RAGCell**，在**成本效益**与**高性能**上实现"双赢"：
  - 用 LLM 构建知识库作为监督信号，**无需大规模预训练**；
  - 通过细胞—文本对齐将文本空间知识迁移到细胞空间，**缓解异质性鸿沟**。

## 二、方法论

### 2.1 核心思想：RAG 作为监督范式
- 论文将 RAG 定义为一个**计算范式**：将参数化知识（模型权重）与非参数化知识（外部可检索索引）解耦，后者在推理时被动态查询以增强预测。
- **关键澄清**：RAG 的概念核心是"检索机制"而非"文本输出本身"。检索到的表示不仅用于对比学习意义上的对齐，还被注入模型以增强对查询细胞的预测（功能上等价于把检索文档拼进 LLM 上下文）。
- RAGCell 的两大支柱：
  1. 用 LLM 构建**细胞级 + 特征级**双层知识数据库，作为训练细胞模型的监督信号；
  2. 将细胞表示与双层知识库的文本嵌入对齐，实现文本→细胞的知识迁移。

### 2.2 细胞模型（轻量级 Patch-based Transformer）
- 输入细胞样本 $X \in \mathbb{R}^{1 \times N_f}$，划分为 $M$ 个 patch，每 patch 为 $P$ 维向量，满足 $N_f = M \times P$（默认 128 个 patch）。
- 加入分类 token $X_{cls}$ 与 1D 位置编码 $E_{pos}$：
  $$X_t = [X_{cls}; X^1_p E; X^2_p E; \dots; X^M_p E] + E_{pos}$$
- 经标准 Transformer 得到细胞表示 $Z_{cell} = \text{Transformer}(X_t)$。
- 由于无需大规模预训练，模型保持轻量。

### 2.3 双层知识数据库构建
- **细胞级数据库**：
  - 模板："This is a single-cell `<omics>` sequence sample with a cell type of `<cell type>`. Please summarize its major function. Use academic language in one paragraph and think step by step."
  - 流程：$Z^c_{text} = \text{EM}(\text{LLM}(\text{Prompt}(Q_c)))$，$Z^c_{text} \in \mathbb{R}^{1 \times F_1}$
  - 实际配置：GPT-4o mini 生成描述 + `text-embedding-3-large` 提取嵌入（3072 维）。
- **特征级数据库**：
  - 模板："Please summarize the major function of gene: `<gene>`. Use academic language..."
  - 流程：$Z^{f_i}_{text} = \text{EM}(\text{LLM}(\text{Prompt}(Q_{f_i})))$，堆叠后得 $Z^f_{text} \in \mathbb{R}^{N_f \times F_2}$
  - 实际配置：GPT-3.5 生成描述 + `text-embedding-ada-002`（1536 维）。
- **幻觉缓解四策略**：
  1. 上下文感知生成（明确模态与任务设定，降低实体歧义）；
  2. 生成后对照策展数据库（NCBI）验证，标记不一致者重新生成或剔除；
  3. 对图中/案例研究中的高影响样本做人工检查；
  4. 将生成描述视为**辅助监督而非真值**，通过鲁棒性检查与消融分析评估敏感性。

### 2.4 细胞—文本对齐
- 特征级文本嵌入按表达量加权聚合：$Z^{f'}_{text} = X \times Z^f_{text}$；
- 拼接双层文本：$Z_{text} = \text{Concat}(Z^c_{text}, Z^{f'}_{text})$；
- 两个独立 MLP 将细胞表示与文本表示投影到同一低维空间（默认 $D=128$）：$H_{cell} = \text{MLP}(Z_{cell})$，$H_{text} = \text{MLP}(Z_{text})$；
- 实例级匹配对比损失：
  $$L_{C2T} = -\frac{1}{B}\sum_i \log \frac{\exp(\cos(H^i_{cell}, H^i_{text}))}{\sum_j \exp(\cos(H^i_{cell}, H^j_{text}))}$$
  $$L_{T2C} = -\frac{1}{B}\sum_i \log \frac{\exp(\cos(H^i_{text}, H^i_{cell}))}{\sum_j \exp(\cos(H^i_{text}, H^j_{cell}))}$$
  $$L = \tfrac{1}{2}(L_{C2T} + L_{T2C})$$
- 目标：拉近配对细胞—文本距离，推远非配对距离，从而把 LLM 语义知识注入细胞模型。

### 2.5 下游任务适配
- **分类类任务**（细胞类型注释、药物敏感性预测）：分类头 $P_{cell} = \text{MLP}(H_{cell})$，交叉熵 $L_{cls} = \text{CE}(P_{cell}, Y_{cell})$ 微调。
- **表示直接评估类任务**（批次效应校正、多组学整合）：不做微调，直接使用细胞表示。
- **稀有细胞类型识别**：以 SOTA 方法 scCAD 为框架，用 RAGCell 的零样本表示替换其原始嵌入（纯零样本），其余算法设置不变。

### 2.6 推理时检索与表示融合
- 以 $H_{cell}$ 为 query，在外部嵌入索引中用余弦相似度检索 top-$k$ 文本表示；
- 相似度归一化注意力加权聚合：$H_{ret} = \sum_{i=1}^{k} \alpha_i H^{(i)}_{text}$，其中 $\alpha_i = \text{softmax}(\text{sim}(H_{cell}, H^{(i)}_{text}))$；
- 融合：$H_{aug} = \text{MLP}([H_{cell}; H_{ret}])$，用 $H_{aug}$ 而非 $H_{cell}$ 送入下游预测头；
- 检索库与文本嵌入构建**不使用测试集标签**，推理时模型参数固定。

### 2.7 新颖性主张
- 核心贡献是**双粒度对比学习策略**：在细胞与特征两个层级把生物语义直接嵌入基因/蛋白/peak 表示空间，形成与既有 cell-language 模型**根本不同的归纳偏置**；
- patch 编码方案与特征级监督**互相强化**（patch 继承了其组成特征的聚合描述），而非简单拼接；
- 由此解锁单组件无法实现的能力：**零样本泛化到训练未见特征、跨模态迁移、生物可解释表示**。
