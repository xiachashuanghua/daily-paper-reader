## 摘要
新测序蛋白质的功能注释仍然是分子生物学中的一个瓶颈：公共数据库中的序列数量增长速度远超人工注释的能力。大多数计算方法将注释视为在固定本体上的多标签分类，这会将预测限制在预定义的标签集内。在本工作中，我们将蛋白质注释作为序列到文本的生成问题进行研究。我们使用 QLoRA（4 位 NF4 量化与低秩适配器）在序列-注释对上微调 3B 参数的 Ministral 3 基础模型。我们采用 LLM 作为专家的评估协议来评估预测：提示一个 GPT 模型作为资深分子生物学注释专家，以二值方式对生物体识别进行评分，并评估功能注释质量。我们得出结论：经 QLoRA 微调的紧凑型 LLM 能够为相当一部分蛋白质生成具有真正生物学价值的注释专家风格注释。我们还讨论了数据质量、模型扩展和证据 grounding 等未来方向，这些方向是使该方法足够可靠以用于实际所必需的。

## Abstract
Functional annotation of newly sequenced proteins remains a bottleneck in molecular biology: the number of sequences in public repositories grows far faster than the capacity for manual curation. Most computational approaches consider annotation as multi-label classification over a fixed ontology, which constrains predictions to a predefined label set. In this work we study the the protein annotation as a sequence-to-text generation problem. We fine-tune the 3B-parameter Ministral 3 base model with QLoRA (4-bit NF4 quantization with low-rank adapters) on sequence annotation pairs. We assess predictions with an LLM-as-expert protocol: a GPT model prompted as a senior molecular-biology curator scores organism identification as binary and function annotation quality. We conclude that QLoRA-fine-tuned compact LLMs can generate curator-style annotations with genuine biological value for a substantial subset of proteins. We also discuss future directions in data quality, model scaling, and evidence grounding that are needed to make the approach sufficiently reliable for practical use.

## 1. 核心问题与整体含义（研究动机与背景）

- **领域瓶颈**：新测序蛋白质的功能注释是分子生物学的瓶颈。UniProtKB 收录数亿条目，但只有 Swiss-Prot 部分由专家人工审编并附带证据标签；人工审编准确但昂贵，无法跟上高通量测序速度，绝大多数条目依赖同源迁移的自动注释。
- **主流范式的两大局限**：多数计算方法把注释当作固定本体（最常用 Gene Ontology）上的多标签分类（如 BLAST、DeepGOPlus，CAFA 挑战赛建立了评估标准）。其一是**预测空间封闭**，分类器只能输出训练过的术语，无法表达本体中没有的功能细微差别；其二是**输出为标识符集合而非描述**，Swiss-Prot FUNCTION 注释中真正有用的底物、相互作用伙伴、调控方向、生理背景等信息被压平或丢失。
- **本文立场**：把蛋白质注释重新表述为**条件文本生成**（sequence-to-text）问题——给定氨基酸序列，直接生成自由文本功能描述。该表述开放、产出策展式散文，可按生物学含义而非标签重叠来评估。
- **研究定位**：已有 Prot2Text、Prot2Text-V2 等多模态系统证明该表述可行，但通常需耦合蛋白编码器（及结构信息）。本文追问：**仅用通用、紧凑、开源的语言模型，输入只有原始氨基酸序列文本，在商品化硬件上做参数高效微调，能获得多少这种能力**。

## 2. 方法论

### 核心思想
- 用 QLoRA 微调 3B 参数的 Ministral 3 基础模型，使其从加空格的氨基酸序列生成"来源生物体 + UniProt 风格 FUNCTION 描述"，统一封装为一个 JSON 对象。
- 采用**基础（非指令微调）checkpoint**：目标任务窄且格式高度固定，监督微调即可定义响应格式，避免与既有指令微调竞争。

### 关键技术细节
- **基础模型**：`mistralai/Ministral-3-3B-Base-2512`，通过 `mistral-common` 的 Tekken tokenizer 分词与模板渲染。
- **量化**：4-bit NF4 量化 + 双重量化，bfloat16 计算；冻结基座权重约占 2.6 GB 显存。
- **LoRA 公式**：对 $W_0 \in \mathbb{R}^{d\times k}$，适配变换为
  $W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} B A x$，其中 $B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$、$r \ll \min(d,k)$。
- **LoRA 配置**：注入每个 Transformer 块的 7 个投影矩阵（`q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj`），$r=64$、$\alpha=128$（$\alpha/r=2$）、dropout 0.05、不训练 bias；可训练参数 **135,004,160 / 3,984,094,208 = 3.39%**。
- **序列表示**：残基间插入单空格（`"M K A V S P ..."`），避免子词 tokenizer 按局部上下文把残基合并成多变的多字符 token，使残基到 token 的映射近似一一对应且位置稳定；序列包在 `<protein>` 标签内，经 Mistral chat 模板渲染为 `<s>[INST]...[/INST]`。
- **目标格式**：`{"function": "Organism; FUNCTION: ..."}`，以 EOS 结束；分号前为生物体，便于确定性拆分与分别评分；JSON 封装保证机器可解析并给出明确停止条件。
- **损失掩码**：prompt 由 tokenized prompt 与 tokenized target 直接拼接（而非两轮对话渲染），保证 prompt token 是训练序列的精确前缀；label 中 prompt 位置设为 −100，仅对答案 token 计算损失；样本截断至 1,536 token。
- **训练设置**：3 epochs，单卡 per-device batch 16 × 梯度累积 2 = 有效 batch 32，共 6,336 优化步；学习率 $1\times10^{-4}$，cosine 调度，1% warmup；paged 8-bit
