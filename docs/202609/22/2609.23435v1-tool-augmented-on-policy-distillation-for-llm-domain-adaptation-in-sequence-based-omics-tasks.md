## 摘要
多组学序列包含复杂的生物模式，然而破译其机制以实现自动化科学发现仍然具有挑战性。当大语言模型（LLM）解释这些序列时，评估其预测和科学推理都至关重要。然而，现有多组学序列任务基准依赖于分类和回归指标，忽略了模型是否掌握潜在的生物学证据。我们提出 OmicsBench，首个面向多组学序列的推理基准，包含 1,160 个经专家验证的问题，涵盖 DNA 调控、RNA 加工和蛋白质功能等六项任务。OmicsBench 要求可追溯的证据链，并使用与领域专家共同开发的实例特定评分细则进行评估。评估 17 个 LLM 揭示了一种反向关系：尽管科学 LLM 在序列分类准确率上优于通用 LLM，但它们无法提供有效证据来支持其预测。一种可能的解释是捷径学习：专用模型可能依赖统计模式，而非科学发现所需的生物机制。受此发现启发，我们提出工具增强同策略蒸馏（TA-OPD），一种后训练方法，用于使序列预测与基于证据的生物推理对齐。在五个 Qwen3.5 模型（0.8B 至 27B 参数）上，TA-OPD 持续增强生物证据基础，同时在大多数任务上提升预测性能。这些增益在不同模型规模上均持续存在，表明更强的序列推理并非仅来自模型容量增加，而是可以通过证据感知训练得到改善。总之，OmicsBench 和 TA-OPD 为诊断多组学 LLM 中的推理失败提供了一个框架，并为使模型预测更好地建立在具有生物学意义的证据之上提供了一条路径。

## Abstract
Multi-omics sequences contain complex biological patterns, yet deciphering their mechanisms for automated scientific discovery remains challenging. As large language models (LLMs) interpret these sequences, evaluating both predictions and scientific reasoning is critical. However, existing benchmarks for multi-omics sequence tasks rely on classification and regression metrics, neglecting whether models grasp the underlying biological evidence. We introduce OmicsBench, the first reasoning benchmark for multi-omics sequences, comprising 1,160 expert-validated questions across six tasks spanning DNA regulation, RNA processing, and protein function. OmicsBench requires traceable evidence chains, evaluated using instance-specific rubrics developed with domain experts. Evaluating 17 LLMs reveals an inverse relationship: while scientific LLMs outperform general-purpose LLMs in sequence classification accuracy, they fail to provide valid evidence to support their predictions. One plausible interpretation is shortcut learning: specialized models may rely on statistical patterns rather than the biological mechanisms needed for scientific discovery. Motivated by this finding, we introduce tool-augmented on-policy distillation (TA-OPD), a post-training method to align sequence prediction with evidence-grounded biological reasoning. Across five Qwen3.5 models spanning 0.8B to 27B parameters, TA-OPD consistently strengthens biological evidence grounding while improving predictive performance on most tasks. These gains persist across model scales, indicating that stronger sequence reasoning does not arise solely from increased model capacity, but can be improved through evidence-aware training. Together, OmicsBench and TA-OPD provide a framework for diagnosing reasoning failures in multi-omics LLMs and a path toward models whose predictions are better grounded in biologically meaningful evidence.

## 2. 方法论

### 2.1 OmicsBench：过程导向的多组学推理基准

- **任务设计**：对齐分子生物学中心法则，分三大类共六项任务，共 **1,160 道专家验证题**：
  - DNA 调控：表观遗传标记预测（EMP, 197 题）、启动子检测（Prom, 219）、转录因子结合位点（TFBS, 216）
  - RNA 加工：RNA 修饰预测（Mod, 101）、非编码 RNA 分类（ncRNA, 215）
  - 蛋白质功能：酶功能预测（EC, 212）
- **构建流程**（数据过滤 → 智能体合成 → 质量验证 → Rubric 构建）：
  - 从 Biology-Instructions 的 34,033 条测试样本出发，用余弦相似度 + 核心集选择（coreset）保留代表性序列，再做分层采样平衡标签，得 5,537 条候选。
  - **多智能体合成框架**：Bio-Agent（Claude-Sonnet-4.5）调用 BLAST（同源搜索）、ViennaRNA（结构预测）、JASPAR（模体扫描）、PubMed API（文献检索）等工具，生成含答案与生物学论证的长文本推理链；Verifier Agent 做**标签一致性**与**逻辑一致性**双重检查，约 1,512 题通过。
  - **专家验证**：3 位领域专家独立评审（科学准确性、证据相关性、推理完整性），多数接受者保留，最终得 1,160 题。

### 2.2 实例化 Rubric 与 Rubric Recall（RR）

- **层级结构**：
  - 任务级维度 \(D_{task}\)：如启动子任务的 {核心元件, GC 含量, TSS 检查, …}。
  - 实例级 rubric \(R_q = \{r_1,\dots,r_k\}\)，每条 \(r=(d,E)\)，\(d\) 为维度，\(E=\{e_1,e_2,\dots\}\) 为从标准答案中抽取的**原子证据单元**。
- **构建流程**：“Define–Decompose–Scale–Verify”：专家定义维度 → 专家对每题 5 个样例做原子分解标注 → Summarizer Agent 借助上下文学习批量扩展 → 专家复核去冗与纠错。
- **规模**：共 **3,745 个 rubric 维度**（约 3.2 维/题）、**11,392 条具体证据**（约 3.0 条/维度）。
- **RR 公式**：
  \[
  \text{RR}(q)=\frac{1}{|R_q|}\sum_{r\in R_q}\mathbb{1}(r\ \text{被}\ \hat{y}_q\ \text{满足})
  \]
  其中 rubric \(r\) 被满足定义为：其证据集合 \(E\) 中**至少有一条原子证据**被模型回答复原。
- **判分协议**：LLM judge（DeepSeek-V3.2），三条判据——(1) 精确实体匹配（如 PDB ID）、(2) 语义等价（容忍表述差异）、(3) 上下文有效性（证据须真正支撑结论，而非误引或幻觉）；并校验定量阈值（如“78% 同一性”满足“≥75%”）。
- **抗刷分设计**：按维度平均而非证据计数，单靠堆字数无法提分；对抗性关键词注入测试中，约 1,000 token 的术语堆砌模板在六项任务上得分均 <1.2%。

### 2.3 TA-OPD：工具增强同策略蒸馏

- **定位**：在 OPD（同策略蒸馏）与 OPSD（同策略自蒸馏）基础上发展。OPD 用更强外部教师；OPSD 让教师与学生同源初始化、仅教师可见真值；**TA-OPD 则把工具型生物医学智能体生成的答案与证据作为“特权信息”只提供给教师**。
- **关键设计**：
  - 教师与学生由同一模型权重初始化，**教师冻结**，只更新学生。
  - 学生仅看任务指令与生物序列并自行生成回答；教师额外看到智能体的答案与支持证据。
  - 逐 token 计算蒸馏信号 = 教师 log 概率 − 学生 log 概率，使用 **sampled-token k1 log-ratio 估计器 + 策略梯度优化**，覆盖学生自己的解释与最终预测全过程。
  - **答案—标签一致性门控**：仅当智能体最终预测与真值标签一致时，该样本才进入训练。
  - 训练数据由 Biomni + DeepSeek-V4-Flash 调用领域工具生成。
- **训练配置**：AdamW，3% warm-up + 常数学习率 \(2\times10^{-6}\)，weight decay 0.01；prompt 上限 8,192 token，response 上限 16,384 token。
- **训练集 TA-OPD-10K**：10,069 条记录（8,686 个唯一输入），分布为 EMP 2,152、Prom 1,784、TFBS 1,670、Mod 1,346、ncRNA 1,678、EC 1,439；已排除与 OmicsBench 评估输入完全相同的样本，并重采样缓解标签不平衡。

- **基准**：OmicsBench 全部 1,160 题；指标为常规预测指标（EMP/Prom/TFBS 用 MCC，Mod 用 AUC，ncRNA 用 Acc，EC 用 Fmax）与 RR。
- **评测对象（17 个 LLM）**：
  - 专有模型 5 个：Claude-Sonnet-4.5、Gemini-3-Pro、GPT-5.2、Grok-4、Qwen3-Max
  - 开源模型 6 个：DeepSeek-V3.2、GLM-4.7、GPT-OSS-120B、Kimi-K2、Llama-4-Maverick、Qwen3-235B
  - 科学模型 6 个：ChatMultiOmics、ChatNT、Intern-S1、Intern-S1-Pro、NatureLM、SciReasoner
- **TA-OPD 实验**：在 Qwen3.5 的 5 个规模（0.8B、2B、4B、9B、27B）上做适配，与官方指令微调版（unadapted）逐一对比；另设 **Qwen3.5-397B** 作为外部参照。

## 6. 主要结论与发现

- **推理退化现象**：科学 LLM 在常规指标上常居首（各列最佳单任务成绩均由科学模型取得，如 ChatNT 在 EMP 达 86.86% MCC、Intern-S1-Pro 在 Prom、SciReasoner 在 TFBS/EC、ChatMultiOmics 在 Mod/ncRNA），但 RR 普遍很低。ChatNT 在 EMP 上 MCC 86.86% 而 RR 为 0%。
- **相关性反转**：通用模型族内预测得分与 RR 呈正相关（r = 0.26），科学模型族内为负相关（r = −0.29

r = −0.29），即科学模型在分类指标上越强，其证据复原能力反而越弱，说明其高分更多来自对标签分布/序列模式的拟合，而非可解释的机制推理；这一“指标—证据背离”正是论文主张需要过程导向评测的直接证据。

- **规模效应的双向性**：模型规模增大可提升预测指标，但对 RR 的改善有限，甚至在某些科学模型上出现负向关联，暗示单纯放大参数或继续在“序列→标签”数据上做指令微调，不足以修复推理退化。
- **TA-OPD 的整体增益**：在 Qwen3.5 的五个规模上，TA-OPD 适配版相对官方指令微调版在**多数任务上同时改善预测指标与 RR**，表明“从智能体的答案+证据中蒸馏”能够把工具使用阶段获得的机制性知识内化进模型参数，且**推理时无需任何工具调用**即可复现。
- **小模型的“跃迁式”收益**：论文报告增益在中小规模上尤为明显，适配后的较小模型可在部分任务上追平甚至超过未适配的更大模型；而 397B 外部参照虽然绝对水平更高，但相对增益空间更小，说明该方法对算力受限场景更具边际价值。
- **任务异质性**：DNA 调控类任务（EMP、Prom、TFBS）与蛋白质 EC 任务获益较稳定，RNA 修饰（Mod）等样本量小、证据稀疏的任务提升相对有限，提示蒸馏效果依赖教师能否获得高质量、可验证的证据链。
- **失败模式（专家定性分析）**：归纳出三类典型错误——(1) **证据幻觉**：引用不存在的模体、PDB ID 或文献结论；(2) **证据—结论脱耦**：罗列了正确证据但未将其与最终预测建立因果链，属于“答对但说不清”；(3) **过度泛化**：把同源家族的共性特征直接套用到具体序列，忽略上下文特定位点。TA-OPD 主要缓解第 (2)(3) 类，对第 (1) 类幻觉的抑制有限。
- **核心论断**：序列组学任务的 LLM 能力评估必须区分“结果正确”与“过程可证”；同策略蒸馏配合工具型教师提供的特权证据，是一条在**不增加推理成本**前提下弥合二者差距的可行路径。

2. **评测范式**：提出过程导向基准 **OmicsBench**，以“实例化 Rubric + Rubric Recall”替代单一准确率，并配套 3,745 个 rubric 维度、11,392 条原子证据，覆盖中心法则三大环节。
3. **抗刷分机制**：以维度平均而非证据计数计分，并通过对抗性关键词注入实验验证其鲁棒性，为“长文本科学推理”评测提供了可复用的设计模板。
4. **训练方法**：提出 **TA-OPD**，把工具型生物医学智能体的“答案 + 证据”作为**仅教师可见的特权信息**，结合答案—标签一致性门控与 log-ratio 策略梯度，实现同策略、全序列（含解释部分）的蒸馏。
5. **开源资产**：发布 **TA-OPD-10K** 训练集与 **TA-OPD-27B** 模型，并显式排除与评测输入重合的样本，为后续研究提供可比较的基线。

---

## 8. 局限性

- **消融不足**：未逐一拆分工具证据、一致性门控、同源教师初始化等设计的作用，方法有效性的归因不够精确。
- **评测规模有限**：6 项任务、1,160 题，单任务 100–220 题，统计功效受限；部分结论（如相关性系数）对样本波动较敏感。
- **判分依赖单一 LLM judge**：RR 全部由 DeepSeek-V3.2 判定，缺少多 judge 交叉验证与人类一致性报告，存在系统性偏置风险。
- **证据质量上限**：教师证据本身由智能体合成并经有限专家验证，若教师证据有误，蒸馏可能放大错误；论文未报告教师证据的错误率估计。
- **任务覆盖**：仅覆盖短到中等长度序列的分类/预测任务，未涉及序列生成、结构预测、跨模态（序列+表型）推理等更复杂场景。
- **算力与成本不透明**：只说明使用最多 8×H200（140 GB），未给出训练时长、GPU 小时、基准构建与大规模评测成本，可复现性与成本评估受限。
- **分布外泛化未验证**：训练集与评测集虽做了输入去重，但同源于 Biology-Instructions，对全新物种、罕见家族或真实临床/工业序列的迁移能力尚不清楚。

---

## 9. 对领域的影响与启示

- **对评测社区**：提示“以准确率论英雄”的做法在多组学场景可能误导模型选型，建议将过程可证性（如 RR 类指标）与结果指标并列报告。
- **对模型训练**：为“工具增强—证据内化—去工具推理”提供了可复制的三段式范式，可迁移到化学、材料、医学等同样依赖外部知识库的科学领域。
- **对科学基础模型**：说明生物基础模型与通用 LLM 的能力互补性——前者擅长表征与预测，后者擅长证据组织与自然语言解释，二者结合（作为教师/工具）比单一路线更有效。
- **对智能体研究**：把智能体从“推理时的外挂”重新定位为“训练时的特权教师”，是一种降低部署成本、同时保留工具收益的思路。

---

## 10. 总体评价

论文在**问题洞察**与**评测设计**上贡献突出：把“模型答对但讲不出理由”这一长期被忽视的现象转化为可量化指标，并给出训练侧的可行解法；评测构建流程（多智能体合成 + 双重一致性校验 + 专家复核 + rubric 分解）规范且可复用。方法侧 TA-OPD 概念清晰、实现代价可控、推理零额外开销，工程价值明确。主要短板在于**缺少消融与成本报告**、**判分单一依赖 LLM judge**、**任务与样本规模偏小**，使其因果结论的稳健性弱于其描述性发现。总体而言，这是一篇**以评测创新带动方法创新**的工作，适合作为“科学推理可解释性 + 领域适配”方向的重要参考基线。
