## 摘要
类器官是三维组织模型，其形态学为肿瘤发展、疾病进展和药物测试提供了重要见解。提取这些形态学特征在很大程度上依赖于人工分割，耗时且费力。此外，进行定量统计分析通常需要定制编程技能和数学背景，这给实验生物学家带来了重大障碍。为解决这些挑战，我们提出了 MorphoOrgaAgent，一个多智能体框架，能够基于自然语言输入实现零样本类器官分割、自动化数据分析和报告生成。该框架主要由三个核心组件组成：TaskUnderstandingAgent，用于识别所请求的测量指标和可视化类型；一个混合分割模块，将源自 Cellpose 的几何提示与文本提示相结合，以引导 SAM3 进行零样本类器官实例分割；以及一个 ReportAgent，用于计算定量指标，并将其与生成的可视化结果一起汇编成结构化报告。我们进一步提出了 MorphoOrgaVQA，一个用于对类器官形态分析中的智能体系统进行定量评估的基准。实验结果表明，MorphoOrgaAgent 能够处理明确的和描述性的用户请求，产生与真值高度接近的测量结果，并在无需人工编程的情况下生成完整的分析报告。完整源代码和 MorphoOrgaVQA 基准已在 https://github.com/peng-lab/MorphoOrgaAgent 公开提供。

## Abstract
Organoids are three-dimensional tissue models whose morphology provides important insights into tumor development, disease progression, and drug testing. Extracting these morphological features relies heavily on manual segmentation, which is time-consuming and labor-intensive. Furthermore, performing quantitative statistical analysis typically requires custom coding skills and a mathematical background, presenting a major barrier for experimental biologists. To address these challenges, we introduce MorphoOrgaAgent, a multi-agent framework that achieves zero-shot organoid segmentation, automated data analysis, and report generation based on natural language input. The framework consists mainly of three core components: a TaskUnderstandingAgent that identifies requested measurements and visualization types; a hybrid segmentation module that combines Cellpose-derived geometric prompts with text prompts to guide SAM3 for zero-shot organoid instance segmentation; and a ReportAgent that computes quantitative metrics and compiles them alongside generated visualizations into a structured report. We further introduce MorphoOrgaVQA, a benchmark designed for quantitative evaluation of agent systems in organoid morphology analysis. Experimental results demonstrate that MorphoOrgaAgent handles both explicit and descriptive user requests, produces measurements closely matching ground truth, and generates complete analysis reports without requiring manual programming. The complete source code and MorphoOrgaVQA benchmark are publicly available at https://github.com/peng-lab/MorphoOrgaAgent.

## 二、方法论

### 2.1 核心思想
- 以**中央共享状态容器 + 三个协作模块**组织流水线，将生物学家的自然语言请求翻译为可机器执行的定量分析流程，全程无需人工编程、无需标注数据。

### 2.2 关键组件与流程
- **MorphoOrgaState（中央状态容器）**
  - 一个 JSON 可序列化的"单一事实来源"，每次用户查询初始化一个实例，保存输入图像路径、原始自然语言查询。
  - 各子智能体与模块顺序读写该状态：TaskUnderstandingAgent 写入分析计划 → 分割模块写入实例掩码 → 指标计算写入统计量 → ReportAgent 汇总成报告。
  - 最终状态持久化到磁盘，形成**完整可审计的中间结果轨迹**，支撑可复现性。

- **TaskUnderstandingAgent（由 GPT-5.4-mini 驱动）**
  - 解析用户查询意图，从**预定义指标池**中选取所需指标（如 `Area_outer`、`Perimeter_outer`、`roundness`、`perimeter_diff`、`ideal_perimeter`、`x`、`y`、`lumen_ratio` 等）。
  - 从**预定义可视化池**中选取可视化类别（`pixel_overlays`、`metric_plots`、`correlation_heatmap`、`none`），并遵循给定的映射决策规则。
  - 将可能含糊、不精确或含错别字的用户查询**重写为精确的科学表述**，并生成 `report_instruction` 交接给 ReportAgent；系统提示强制输出严格 JSON 的 `AnalysisIntent` 对象。

- **混合提示分割模块（Hybrid-Prompt Segmentation）**
  - 动机：SAM3 虽支持文本提示分割，但其训练以自然图像为主，对"organoid"这一领域概念表征不足；Cellpose 能提供生物对象的粗略定位，但对陌生形态可能漏检或边界不准。
  - 做法：用 **Cellpose 生成的掩码作为几何提示**，配合文本提示 **"cell cluster"**，共同引导 **SAM3** 完成精细化的零样本实例分割。
  - 掩码存入 MorphoOrgaState 后，调用预定义的指标计算与可视化函数，所有统计量（实例级与群体级）均从掩码导出。

- **ReportAgent（由 GPT-5.4 驱动）**
  - 读取 MorphoOrgaState 中的原图、分割结果与统计量，直接回答经 TaskUnderstandingAgent 精炼后的查询，并显式引用证据。
  - **抗幻觉机制**：系统提示严格限制其仅基于状态中的信息作答，**禁止重算、修改或覆盖任何数值与对象计数**；若证据缺失须明示，并需说明局限与不确定性；仅输出 Markdown。
  - 关键设计：LLM 只作为**对预计算状态的推理引擎**，数值由确定性代码产生，从机制上规避数值幻觉。

### 2.3 评估指标公式
- 采用**绝对百分比误差（APE）**衡量数值精度：
  - ε = |(V_pred − V_GT) / V_GT| × 100%
  - 其中 V_pred 为智能体预测的标量值，V_GT 为由专家标注掩码解析计算得到的真值。

## 六、主要结论与发现

- **定量精度（中位 APE，Table 1）**：
  - **圆度（Roundness）最优**：单极值查询 **1.54%（clear）/ 1.56%（open）**；三分位均值 **2.48% / 2.51%**，表明系统能稳健捕捉全局形态规则性。
  - **面积（Area）**：单极值 **16.77% / 17.40%**；三分位均值显著退化至 **38.74% / 36.77%**。
  - **周长（Perimeter）**：单极值 **15.36% / 15.36%**；三分位均值 **22.03% / 22.24%**，在群体聚合下比面积更稳定。
  - **粗糙度（Roughness）最困难**：单极值 **46.02% / 46.02%**；三分位均值 **31.75% / 33.74%**。原因是粗糙度定义为真实周长与理想周长之差，高度依赖像素级边界保真度，对分割噪声极其敏感。
  - **关键发现**：clear 与 open 两种措辞在所有指标与任务上误差曲线几乎一致，说明系统能**将含糊的生物学口语准确解码为正确的分析操作，且不牺牲执行精度**。
- **定性对比结果**：
  - 分割质量：本文混合 Cellpose–SAM3 模块优于 Omega 所用 StarDist 的零样本分割效果。
  - 报告数值：中位面积报告值 —— Agentic-J **1,235**、Omega **761**、MorphoOrgaAgent **5,771.5**，真值 **5,749**；本文相对误差仅 **0.39%**。
  - 失败模式分析：Omega 因分割不准导致数值偏差；Agentic-J 虽使用完全相同的掩码，却**默认采用 convexity 等通用指标**衡量边界粗糙度，未使用领域特异的形态描述符，因而结果偏离。
  - 作者强调两个基线本身是能力很强的通用生物图像平台，其局限源于**通用设计难以承载领域定制的形态学特征**。
- **流程正确性**：在复杂查询中，系统正确统计目标群体（N = 129）、筛出前 10%（13 个）`perimeter_diff` 最高的类器官，并给出中位面积 5,771.5、范围 105.00–22990.00 等结构化报告，且区分了"边界不规则"与"整体低圆度"。

- **分割与统计的耦合风险**：整个流程的数值精度最终受制于上游分割质量，但系统对分割失败**没有显式的质量校验或不确定性报告机制**；ReportAgent 虽被禁止改数，却无法识别"输入掩码本身就错了"这一情形，可能输出看似严谨实则失真的报告。
- **"零样本"声称的边界**：所谓零样本仅指无需在类器官数据上训练，但 Cellpose 与 SAM3 本身仍是预训练模型，其泛化能力受训练分布限制；论文未报告在**明场 vs. 荧光、不同物种/器官来源、不同成像模态**下的性能分层，因此跨域稳健性证据不足。
- **人机交互维度缺失**：未评估用户对报告的信任度、可解释性满意度、纠错交互（如用户可否质疑并触发重跑）等 HCI 层面的关键指标，而这恰是"面向生物学家的工具"能否被采纳的核心。
- **语言与多模态输入范围有限**：基准问题为英文且以文本为主，未涉及多语言、多轮对话、多图批量对比、时间序列（类器官生长追踪）等真实使用场景。

## 九、可复现性与开放资源

- **已公开内容**：论文声明公开代码、MorphoOrgaVQA 基准（机器可读问题集 + 真值生成脚本），并在附录 B 中给出完整系统提示词，这在同类智能体论文中属于透明度较高的做法。
- **可复现性优势**：
  - 真值由确定性脚本从专家掩码导出，任何人可在相同数据上重建评测，**排除了主观标注与 LLM 评分的漂移**。
  - 中央 JSON 状态的可序列化设计，使每一步中间产物（分析计划、掩码、统计量、报告）均可被检视，便于调试与审计。
- **可复现性风险**：
  - 依赖闭源 LLM（GPT-5.4 / GPT-5.4-mini）与特定版本的 SAM3、Cellpose，**版本迭代可能改变输出**，长期复现需冻结 API 快照或本地化模型。
  - 未报告随机性控制措施（如温度、随机种子、多次运行方差），单次运行的数值是否稳定无从判断。
  - 定性对比中的提示词、Omega/Agentic-J 的配置细节（模型版本、参数）未完整披露，基线难以精确复刻。

## 十、对后续研究的启示

- **评测方向**：
  - 亟需**标准化的类器官分割量化基准**（Dice/IoU/边界 F-score），将"分割误差"与"推理/统计误差"解耦，才能定位粗糙度、面积等高误差指标的根因。
  - 建议引入**分层误差报告**（按器官类型、成像模态、实例密度、边界复杂度），而非仅给全基准中位 APE。
- **方法方向**：
  - 混合提示（几何先验 + 文本语义）是一条有前景的零样本路线，后续可探索**提示自动搜索**或**自一致性校验**（多次分割取共识、剔除离群实例）。
  - 可在 ReportAgent 前增加**统计合理性校验层**（如实例数骤变、面积分布异常检测），把"数值幻觉"防护扩展到"输入质量幻觉"防护。
  - 可探索**本地开源 LLM 替代闭源 API**，以缓解成本、隐私与版本漂移问题。
- **系统方向**：
  - 从单图单轮扩展到**批量队列、纵向时间序列、多模态（明场+荧光）联合分析**，并支持用户对中间结果的人工干预与回滚。
  - 引入**成本-精度权衡报告**（API 调用次数、token 消耗、单图推理时延），使工具的实际可用性可被量化评估。

## 十一、总体评价与定位

- **定位**：MorphoOrgaAgent 是一篇典型的**"LLM 智能体 + 领域工具链"系统论文**，其贡献重心在**系统集成与工作流自动化**，而非新的分割算法或新的生物学发现。
- **真正的核心创新**在于三点：
  1. **混合提示零样本分割**——用 Cellpose 的几何掩码为 SAM3 补足领域语义短板，规避标注依赖；
  2. **确定性数值 + 受限 LLM 叙述**的抗幻觉架构——把 LLM 严格限制在"计划、重写、叙述"三处，数值一律由代码产生；
  3. **MorphoOrgaVQA 基准及其真值生成协议**——为类器官形态 VQA 提供了可复现的评测起点。
- **现实价值**：对实验生物学家而言，确实把"标注 + 写代码 + 统计"三步压缩为"自然语言提问"，在**探索性、批量初筛**场景下有明显效率增益。
- **主要保留意见**：在**需要精细边界或严格群体统计**的场景（面积三分位均值、粗糙度）中，约 30%–46% 的中位 APE 尚不足以支撑定量结论；且缺少消融、缺少与领域专用模型的定量对照、缺少算力与成本披露，使"相对现有方案究竟优越多少、代价几何"这一关键问题仍未被回答。
- **一句话结论**：这是一篇**架构设计扎实、工程完成度高、评测协议客观但覆盖偏窄**的系统工作；它清晰地展示了"零样本分割 + 确定性统计 + 受限 LLM 叙述"这一范式的可行性与边界，但要成为类器官实验室的日常工具，仍需在分割量化评估、指标覆盖广度、消融证据与成本透明度上补足短板。
