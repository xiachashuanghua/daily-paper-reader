## 摘要
代谢组学知识分散在不同的异构资源中，且难以转化为预测性表示。我们开发了MetaboLLM，这是一种通过持续预训练、监督微调和结构化检索进行适配的代谢组学专用大语言模型，以及MetaboLLM-GIN，后者利用图同构网络将生成的生化描述转换为用于患者水平预测的代谢物图。在四个骨干家族中，MetaboLLM在代谢组学知识、关系和描述任务上均优于对应的基础模型和医学适配模型，并迁移到了外部公开基准上。MetaboLLM-GIN在冠状动脉旁路移植术后应激性高血糖预测（AUC 0.8616）和绝经后激素方案分类（AUC 0.8123）中取得了最高的AUC，优于传统模型、替代图构建方法以及由未适配或非检索LLM配置生成的图。模型解释进一步在这两个应用中产生了具有生物学意义的发现。这些结果表明，领域专用语言模型可以将异构生化知识组织成预测性且可解释的代谢物图表示。

## Abstract
Metabolomics knowledge is distributed across heterogeneous resources and remains difficult to translate into predictive representations. We developed MetaboLLM, a metabolomics-specialized large language model adapted through continual pretraining, supervised fine-tuning, and structured retrieval, together with MetaboLLM-GIN, which converts generated biochemical descriptions into metabolite graphs for patient-level prediction using a graph isomorphism network. Across four backbone families, MetaboLLM outperformed corresponding base and medically adapted models on metabolomics knowledge, relational, and description tasks, and transferred to an external public benchmark. MetaboLLM-GIN achieved the highest AUC for stress hyperglycemia prediction after coronary artery bypass grafting (0.8616) and postmenopausal hormone-regimen classification (0.8123), outperforming conventional models, alternative graph constructions, and graphs generated from unadapted or non-retrieval LLM configurations. Model interpretation further produced biologically meaningful findings in both applications. These results show that domain-specialized language models can organize heterogeneous biochemical knowledge into predictive and interpretable metabolite graph representations.

- 已有整合工作主要服务于标识符映射、网络调和、模型互操作性和功能富集，并未形成统一的、可供语言模型学习的知识表示。
- 现有生物医学大语言模型（如 Med-PaLM、PMC-LLaMA、Meditron、Me-LLaMA 等）均以临床文本、文献和笔记为训练信号，缺乏以代谢物、反应、酶为基本实体的领域适配。
- 代谢组学领域已有的 LLM 应用（如 DeepMet、MetaboliteChat、MetaboT、MetaBench）多将语言模型用作结构编码器、查询接口或评测对象，并未回答“语言模型能否整合跨数据库生化知识并构建关系表示”这一核心问题。
- 进一步地，从语言知识到患者水平预测的桥梁尚未建立：传统代谢物网络（如 MetaMapp、FELLA、MetaKG、M-GNN、MP-GNN 等）要么依赖人工注释，要么基于数据驱动相关性，难以兼顾生物关系覆盖与预测性能。

  (1) 能否开发一个代谢组学专用 LLM，统一整合跨数据库的生化事实与关系？  
  (2) 该模型学到的知识能否转化为比传统通路图、反应图、相关性图更优的预测性代谢物图？

## 2. 方法论

### 2.1 整体框架
- 构建**统一代谢组学知识语料库**：整合 KEGG、HMDB、PubChem、SMPDB，通过多种标识符（KEGG ID、HMDB accession、PubChem CID、InChIKey、CAS 等）利用 union-find 算法对齐，共得到 237,243 个代谢物、2,359 条通路、12,323 个反应、5,993 个酶。
- **持续预训练（CPT）**：将结构化记录转化为模板化的自然语言样本（化合物、通路、反应+酶三个层级），使用因果语言建模目标进行 LoRA 参数高效微调，使模型内化代谢组学术语和事实知识。
- **监督微调（SFT）**：构造四类任务数据——知识回忆（如名称→分子式、分子式→名称、代谢物→通路）、类别识别（代谢物/反应类别）、关系识别（共享反应代谢物、反应→酶、反应-酶配对验证）、描述生成（代谢物、通路、酶描述，以及“结构丰富/结构贫乏”代谢物描述）。使用多轮对话格式，仅对助手回复 token 计算损失。
- **结构化检索增强（RAG）**：基于 Qdrant 向量数据库，通过标识符约束的元数据过滤，先检索与目标代谢物直接发生反应或共享通路的候选代谢物，再用 ChemBERTa（化学相似度）和 PubMedBERT（生物相似度）的加权平均进行排序，将反应与通路上下文注入提示词，生成检索增强的代谢物描述。
- **MetaboLLM-GIN 图构建与预测**：
  - 对每个被测代谢物生成检索增强的文本描述 → 用生物医学文本嵌入模型计算全部代谢物描述间的余弦相似度矩阵 → 取相似度最高 top-k 对作为无向边，构成共享的知识图拓扑。
  - 节点特征为样本特异性的代谢物丰度（可包含多个时间点或变化量）。
  - 使用图同构网络（GIN）进行图级分类：每层更新公式为  
    \(h_v^{(l)} = \mathrm{MLP}^{(l)}\left((1+\epsilon^{(l)})h_v^{(l-1)} + \sum_{u\in\mathcal{N}(v)} h_u^{(l-1)}\right)\)  
    ；将原始节点特征与各层读出向量拼接得到图表示；有临床协变量时再拼接协变量，最终经 MLP 分类器输出二分类 logit，使用二元交叉熵损失训练。
- 模型解释：使用 GNNExplainer 学习节点/边重要性掩码，聚合得到全局重要性排名，用于通路富集和边-已知生化关系一致性验证。

## 6. 主要结论与发现

- MetaboLLM（尤其 MetaboLLM-Qwen3-4B）在内部代谢组学知识、关系和描述任务上全面超过未适配骨干、CPT-only 和通用医学适配模型，平均准确率达 79.07%。
- 四个骨干家族（Qwen3-4B/8B、Gemma-3-4B、Llama-3.2-3B）上的一致提升表明方法具有跨架构普适性。
- RAG 能进一步提升描述生成质量，但检索只是补充而非替代模型参数中已获得的知识；MetaboLLM 无检索的 BLEU-2 仍高于骨干模型有检索。
- 在外部 MetaBench 上，MetaboLLM 在 Knowledge 任务（最高 56.42% 准确率）和 Understanding 任务（BERTScore 85.19）上均取得最好成绩，且描述生成分数超过原报告中的前沿模型参考范围。

- 由检索增强的 MetaboLLM 描述生成的知识图优于随机图、相关性图、通路图、反应图以及未适配/无检索 LLM 生成的图，且最佳图通常较稀疏（200 边/100 边）。
- 图解释分析显示，重要边与已知共享通路/反应关系显著一致，重要代谢物富集于与手术应激、糖皮质激素、胆汁酸、视黄醇、胰岛素抵抗等相关的通路，支持其生物学合理性。

## 7. 优点

- **首次系统性地将代谢组学专用 LLM 与下游患者级预测图构建闭环**：从多数据库整合、语言模型适配、检索增强描述生成，到图神经网络预测和生物学解释，形成完整技术链路。
- **方法通用性强**：不依赖特定模型架构；GIN 图构建仅需代谢物描述，可推广到任何代谢组学数据集。
- **对照实验设计严密**：涵盖医学适配模型、基础模型、CPT-only、MetaboLLM，以及 RAG/图类型/稀疏度/随机种子等大量消融，统计检验规范。
- **可解释性有据**：GNNExplainer 重要性边与已知通路/反应的匹配显著高于随机，通路富集结果与独立文献证据吻合（如 CABG 围术期皮质醇升高、胆汁酸变化、视黄醇下降等）。

- **未与专有前沿模型公平对比**：未在相同提示、解码条件下直接与 GPT-5、Claude Sonnet 4 等比较，结论仅限于“在所选开源模型和医学模型中表现更好”。
- **临床样本小且单中心**：CABG 队列仅 61 人，重复交叉验证不能替代独立前瞻队列验证；激素分类数据集为单时间点观测，非外部结局验证。
- **代谢物注释不确定性**：非靶向代谢物基于 Mummichog 推定注释，身份误差可能向描述生成、图构建和通路分析传播。
- **图密度选择存在过拟合风险**：基于同一队列预测性能选择最佳边数，可能导致绝对性能偏高；作者也承认该最优值未必普适。
