## 摘要
大型语言模型智能体在数据驱动的科学发现任务中展现出良好的能力，其中智能体与执行环境交互并生成统计性结论。长期的科学分析仍然受到缺乏基于真实世界科学数据的过程监督环境的限制。本文介绍了 SciDisco，一个可在过程可验证环境中训练科学发现智能体的可扩展框架。SciThèque 将假设、数据集、隐藏证据图和验证器整合为任务环境，在此环境中可以在交互过程中检查分析进展。基于DAG的轨迹合成利用这些环境构建经过验证器过滤的多轮演示。DiscoPO 随后将环境作为训练信号的来源，为产生可验证分析证据的动作分配回合级信用。实验表明，SciDisco-14B 在假设驱动的科学数据分析基准上达到了最先进水平。

## Abstract
Large language model agents have shown promising capabilities in data-driven scientific discovery tasks, where an agent interacts with an execution environment and produces a statistical claim. Long-horizon scientific analysis remains constrained by the lack of process supervised environments over real-world scientific data. This paper introduces SciDisco, a scalable framework for training Scientific Discovery agents in process-verifiable environments. SciThèque compiles hypotheses, datasets, hidden evidence graphs, and verifiers into task environments where analytical progress can be checked during interaction. DAG-grounded trajectory synthesis uses these environments to construct verifier-filtered multi-turn demonstrations. DiscoPO then uses the environment as the source of training signal, assigning turn-level credit to actions that produce verifiable analytical evidence. Experiments show that SciDisco-14B reaches state-of-the-art on hypothesis-driven scientific data analysis benchmarks.

- **核心问题**：如何构建可扩展的、可执行且可验证的科学发现训练环境，并在此基础上训练智能体，使其能够学会**交互式分析策略**（如何时检查数据、选择方法、检验假设、修订分析），而不是仅仅依靠提示词或单轮推理。
- **整体含义**：论文提出 SciDisco 框架，将科学数据集转化为带隐藏证据图（DAG）与验证器的交互环境，从而把“分析进展”转化为可验证的回合级训练信号，为科学发现智能体提供一种可扩展的端到端训练范式。

## 2. 方法论：SciDisco 框架

SciDisco 是一个三阶段流水线，核心思想是用“隐藏证据 DAG”作为统一接口，把任务构建、轨迹合成和策略优化对齐到同一个可验证环境中。

### 2.1 SciThèque：可验证环境构建

- 将科学数据集按模态（表格、时序、空间、序列、图）分类，并用模板库与外部 LLM 生成候选假设，再通过参考分析执行与验证器检验来“物化”为训练环境。
- 每个任务表示为 `u_j = (h_j, d_j, v_j)`，其中 `h_j` 为假设，`d_j` 为数据集，`v_j` 为验证器。
- 验证器基于一个**隐藏证据 DAG** `g_j = (V_j, A_j)`：每个节点代表一个可验证的科学状态转换（如数据检查、模型拟合、诊断检查、稳健性分析），边表示前置依赖；只有“前沿节点”可在当前回合被验证。
- 环境将任务提示、数据文件、代码执行沙箱暴露给智能体，而验证器逻辑、证据 DAG、参考值等保持隐藏，从而避免信息泄漏。

### 2.2 DAG-Grounded Trajectory Synthesis（轨迹合成）

- 使用 SciThèque 环境生成用于 SFT 冷启动的多轮演示：按 DAG 的依赖关系安排私有“过渡计划”，为每个节点生成可执行的程序变体。
- 每次执行后，验证器检查该回合是否确实建立了预期的状态转换；未通过（如代码失败、无证据、匹配错误节点、重复工作等）的轨迹被拒绝。
- 保留的轨迹 `D_SFT = {τ_j,l | A_j(τ_j,l, g_j)=1}` 必须是完整通过 DAG 节点、且最终提交与已验证状态一致的多轮对话。
- 保留的语料中共有 **5,620 条验证轨迹**。转换训练数据时会移除调度器标签、隐藏节点 ID、参考值等，避免泄漏。

### 2.3 DiscoPO：回合级信用分配强化学习

- DiscoPO 保留 GRPO 的组归一化优势计算，但将奖励从轨迹级改为**回合级过程奖励**。
- 定义 DAG 进展势函数：
  - `Φ_j(C) = |C ∩ P_j| / |P_j|`，其中 `P_j` 为所有必需的可执行原语节点加终止提交节点。
- 回合奖励为势函数差分：
  - `r_{j,k,t} = Φ_j(C_{j,k,t+1}) - Φ_j(C_{j,k,t})`；等价地，被接受的节点（含有效提交）得 `1/(N_j+1)`，否则为 0。
- 对同一任务采样的 G 条轨迹，计算同回合基线和回合优势：
  - `b_{j,t} = (1/G) Σ_k e r_{j,k,t}`
  - `A_{j,k,t} = e r_{j,k,t} - b_{j,t}`
- 策略优化使用 PPO 截断代理目标，将回合优势分配给该回合生成的所有 token（掩蔽观察 token）。组内无差异（优势全零）的批次被过滤，以避免无信号更新。

## 3. 实验设计

### 3.1 基准与数据集

- **DiscoveryBench**：测试智能体能否根据数据集和发现目标生成科学假设，评估指标为平均假设匹配分数（HMS）。
- **DABStep**：450 个多步业务数据分析任务，分 easy（72）和 hard（378），评估易/难准确率及加权平均准确率。
- **DataSciBench**：端到端数据科学工作流，通过程序化 Task–Function–Code 检查评估数据准备、分析、建模、可视化等，报告成功率、完成率及细粒度 F1–F5。

### 3.2 对比方法

## 6. 主要结论与发现

- **SciDisco-14B 在 DiscoveryBench 上取得 35.2% 平均 HMS**，超过最强专有模型 GPT-5 Mini（26.9%）、最强开源模型 Intern-S1-Pro（34.7%）和最强相关方法 DeepAnalyze-8B（25.9%）。
- **在 DataSciBench 上取得 56.2% 成功率、61.0% 完成率**，超过所有相关方法，接近最强专有/开源模型水平。
- **在 DABStep 上表现较弱（17.8% 平均准确率）**，低于 DeepAnalyze-8B（38.9%）和 Claude-Sonnet-4（29.7%），说明当前训练分布更适用于“科学假设验证”而非泛化的业务多步分析。
- 消融实验表明：SFT 是最大的首阶段收益来源；在 SFT 基础上，GRPO 提升有限，而 **DiscoPO（回合级验证信号）带来最大增量**，尤其体现在 Data Modeling 和 Data Exploration 子任务上。
- 主要结论：可验证的中间分析证据可以转化为有效的回合级过程监督，从而提升科学发现智能体的数据分析和假设生成能力。
