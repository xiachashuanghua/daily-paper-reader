## 摘要
生物医学多跳问答（QA）要求模型在疾病、药物、蛋白质和表型等中间实体之间连接证据。现有智能体通常依赖静态检索工作流或粗粒度的提示重写，这可能在需要更新推理流程时导致指令漂移。我们提出了SSE-Bio，一种具有智能检索策略的结构化自进化智能体，用于多跳生物医学推理。SSE-Bio不是全局重写智能体指令，而是维护一个结构化状态，通过可训练的代理策略选择性地检索知识三元组和先前模板，并通过细粒度的模板编辑改进其推理记忆。为了优化检索决策，我们引入了一种基于组相对策略优化的代理训练策略，其中代理通过替代检索选择上的决策对比组进行改进。在三个生物医学多跳QA基准上的实验表明，SSE-Bio始终优于现有基线，在BioHopR上比最强的自进化基线提高了6.56个绝对百分点。

## Abstract
Biomedical multi-hop question answering (QA) requires models to connect evidence across intermediate entities such as diseases, drugs, proteins, and phenotypes. Existing agents typically rely on static retrieval workflows or coarse-grained prompt rewriting, which can lead to instruction drift when reasoning procedures need to be updated. We propose SSE-Bio, a structured self-evolving agent with an agentic retrieval policy for multi-hop biomedical reasoning. Instead of globally rewriting agent instructions, SSE-Bio maintains a structured state, selectively retrieves knowledge triplets and prior templates through a trainable proxy policy, and improves its reasoning memory through fine-grained template editing. To optimise retrieval decisions, we introduce a proxy-training strategy based on group relative policy optimization, where the proxy is improved through decision-contrastive groups over alternative retrieval choices. Experiments on three biomedical multi-hop QA benchmarks show that SSE-Bio consistently outperforms existing baselines, achieving an improvement of 6.56 absolute points over the strongest self-evolving baseline on BioHopR.

- **研究背景**：生物医学多跳问答（Multi-hop QA）是证据驱动的生物医学发现（如疾病理解、药物重定位）中的关键任务。模型需要跨多个实体（疾病、药物、蛋白质、表型等）连接证据，构建推理链。例如，一个面向疾病的问题可能需要先识别与疾病关联的桥接蛋白，再推断与该蛋白相关的药物。
- **现有方法的不足**：
  1. **静态检索工作流**：许多RAG模型虽然引入外部知识，但缺乏对推理路径的显式验证与反馈，导致中间桥接实体解析失败、推理链漂移，且在多答案场景下可能过早停止、遗漏部分正确答案。
  2. **粗粒度记忆更新**：现有自进化智能体（如STELLA）通过全局提示重写来更新记忆，局部失败可能改变整个推理脚手架，导致**指令漂移**（instruction drift）。
- **核心动机**：需要一个更可控的框架，将**显式检索控制**与**细粒度记忆演化**相结合，使证据使用和记忆更新都更加受限、可控、可审计。

## 二、论文提出的方法论

### 2.1 总体框架

SSE-Bio 是一个四组件迭代式智能体框架：

| 组件 | 角色 |
|---|---|
| **Manager**（规划器） | 维护结构化状态（短期记忆），构建查询特定计划，成功后添加/编辑模板 |
| **Proxy**（检索决策器） | 唯一可训练组件，根据当前结构化状态决定是否检索知识三元组和/或历史模板 |
| **Dev agent**（执行器） | 按计划执行，生成中间答案和推理轨迹 |
| **Critic**（评估器） | 在无金标准答案条件下评估推理与答案质量，返回结构化反馈 |

### 2.2 结构化记忆（Structured Memory）

- **短期状态** $u_t$ 包含四个字段：
  - **task type**：当前问题的关系模式（用于模板检索查询）
  - **information gap**：下一步推理缺失的证据（用于知识三元组检索查询）
  - **feedback**：Critic 对当前轨迹的结构化评价
  - **retrieval state**：已检索外部证据的摘要
- **长期模板记忆** $\mathcal{E}$ 中每个模板包含五个字段：
  - task type、reasoning flow（可复用推理流程）、verification criteria（验证标准）、tool-use policy（工具使用策略）、failure warning（常见错误警告）
- **细粒度模板编辑**：当新成功轨迹与检索到的模板对齐时，仅局部更新需要精炼的字段（如仅改验证标准），而非重写整个模板；不对齐时则蒸馏新模板。

### 2.3 智能检索策略（Agentic Retrieval Policy）

- 动作空间：$a_t \in \mathcal{A} = 2^{\{KG, TPL\}}$，共四个动作（都不检索/仅知识三元组/仅模板/两者都检索）。
- **知识三元组检索**：用 information gap 作为查询，通过 BiCA 编码，经 schema 兼容性和去重过滤后返回 top-5 三元组。
- **模板检索**：用 task type 作为查询，按兼容性得分 $s_{tpl} = 0.60 c_{tpl} + 0.25 m_{schema} + 0.15 m_{ans}$ 返回 top-1 模板。

### 2.4 Proxy 策略训练（两阶段）

**第一阶段——SFT 初始化**：
- 为每个结构化状态 $u_t$，通过比较四个检索分支的 rollout 奖励，选择最高奖励动作作为伪标签。

**第二阶段——GRPO 优化**：
- **决策对比轨迹生成**：从同一推理状态扩展替代检索动作，形成匹配的 rollout 分支；仅在前几轮分支，按剪枝规则（违反关系模式、残留信息缺口、不支持的桥接实体）过滤。

- **奖励塑形**：
  $$R(\tau) = \lambda_o R_{out}(\tau) + \lambda_b R_{beh}(\tau)$$
  - 结果奖励 $R_{out}(\tau) \in \{0,1\}$：最终答案是否匹配金标准。
  - 行为奖励 $R_{beh}(\tau)$：关键步骤（桥接解析、答案验证）被检索证据支持的比例，避免仅靠答案正确性导致的稀疏奖励问题。

- **组相对优势**：$A_i = \frac{r_i - \mu(r)}{\sigma(r) + \epsilon}$，基于同一轨迹组内相对比较。

- **动作级 GRPO 目标**：
  $$J_{GRPO} = \mathbb{E}_i\left[\min(\rho_i A_i, \text{clip}(\rho_i, 1-\epsilon_c, 1+\epsilon_c) A_i) - \beta \cdot KL\right]$$
  其中 $\rho_i = \frac{\pi_\theta(a_i|u_i)}{\pi_{\theta_{old}}(a_i|u_i)}$，并对冻结的 SFT 参考策略做 KL 正则。

## 六、主要结论与发现

1. **整体性能**：SSE-Bio 在 BioHopR 全部 4 项指标上均显著超越 STELLA，单答案 Both cor 从 9.96 提升至 16.52（+6.56 绝对点），精度提升也在多答案设置中保持。
2. **跨域泛化**：零样本迁移到 MedHop 和 HLE 后仍保持领先，说明学到的检索策略具有可泛化性。
3. **Proxy 的有效性**：移除 Proxy后性能显著退化；学习到的 Proxy 优于任何固定检索策略（如始终检索两者），表明改进并非单纯来自检索更多上下文。
4. **结构化状态与细粒度编辑缺一不可**：单独引入只恢复部分差距，两者结合效果最佳。
5. **GRPO 优于 SFT**：在相同骨干下进一步提升了检索决策质量。
6. **仍有提升空间**：Oracle 检索边界分析显示，更强证据和模板匹配可进一步提升（Both cor 16.52 → 18.06），说明检索质量仍是当前瓶颈。
7. **关系类型泛化**：所有 12 种关系类型均有提升，但在 Drug:Disease:Protein 等结构上提升较小，多答案始终低于单答案，反映多答案覆盖的更高难度。

## 七、优点

1. **统一可控的框架设计**：将短期结构化状态追踪、长期模板记忆与显式检索管理整合到一个框架中，使得推理状态、检索决策和记忆演化都基于同一显式结构，避免了分散自由文本带来的不稳定性。
2. **细粒度自演化机制**：模板只编辑需要更新的局部字段（平均修改 1.42 个字段 vs 粗粒度重写的 3.28 个），保留 88.0% 无关字段，显著降低指令漂移与矛盾指令的产生率。
3. **决策对比式 GRPO 训练**：从同一状态扩展替代检索动作形成对比组，在匹配推理上下文下评估各检索分支，结合答案正确性（结果奖励）与证据支持程度（行为奖励），缓解了稀疏奖励问题。
4. **训练目标的完整性**：SFT 伪标签覆盖全部四种检索动作（同时、仅三元组、仅模板、均不），说明 Proxy 学到的是状态相关的多样化检索策略，而非简单的固定规则。
5. **实验设计严谨**：固定 Manager/Critic/Dev 骨干，隔离检索策略学习的贡献；包含显著性检验、Oracle 上限分析、噪声鲁棒性、提示/API 敏感性等多维度验证。

## 八、不足与局限

1. **依赖检索质量**：Oracle 分析表明，更强证据和模板匹配仍可带来约 1.5–2.0 点提升，当前检索器（BiCA）是性能瓶颈之一。
2. **模板记忆的长期维护问题**：虽有细粒度编辑，但模板仍可能随时间冗余、过时或冲突，缺乏记忆整合、剪枝与来源追踪机制。
3. **可复现性受限**：
   - 依赖固定的商业 API（Gemini-2.5-Pro、Claude-4.5-Sonnet），受提示细节和 API 行为影响。

4. **效率成本**：以更高 token 用量换性能（28.3M vs 23.6M [Biomni]、21.2M [STELLA]），但单例 token 开销（约 12.4K）和 API 成本（约 $0.047）仍处于可接受范围，且本地 Proxy 推理不增加商业 API 调用；不过，随着任务规模扩大，模板库增长可能进一步推高 token 消耗。
5. **评估维度较为单一**：主指标依赖答案与金标准的嵌入余弦相似度匹配，对推理过程本身（如中间桥接实体选择的合理性、证据引用的忠实性）缺乏自动化质量度量；人工审计仅在小规模样本上开展，覆盖面有限。
6. **多答案覆盖仍是短板**：多答案场景下的 Both cor 明显低于单答案，尤其在 "Same Query and Bridge" 结构模式中，说明框架对答案集合的完整性管理（如何时停止扩展、如何避免冗余）仍缺乏专门机制。

## 九、总结与展望

### 9.1 总体评价

SSE-Bio 的核心贡献在于**将自进化智能体的记忆更新粒度从"全局重写"下沉到"字段级编辑"，并将检索决策从一个隐式的内部过程提升为显式可训练的策略**。通过 Manager 维护的结构化状态、Proxy 学习的动作策略以及 Critic 提供的无标注反馈，三个环节在同一显式表示上闭环迭代，既增强了证据使用的可控性与可审计性，也缓解了粗粒度记忆演化带来的指令漂移问题。实验结果验证了这一设计在生物医学多跳问答中的有效性，其跨库零样本泛化能力也说明学到的检索策略具备一定的任务无关性。

### 9.2 未来工作方向

1. **突破检索质量瓶颈**：Oracle 边界分析显示更强证据检索可带来约 1.5–2.0 个百分点的提升，未来可考虑以小型 LLM 检索器替代 BiCA，或将检索器纳入端到端联合训练。
2. **记忆生命周期管理**：引入模板去重、一致性校验、来源追踪与过期剪枝机制，构建完整的记忆维护闭环，避免模板库随任务累积而冗余冲突。
3. **策略跨骨干迁移**：当前 Proxy 在固定代理骨干上训练，未来可探索骨干无关的检索策略表征，或通过蒸馏将策略迁移到更小、更快的执行模型上。
4. **多答案覆盖专项优化**：设计覆盖导向的奖励项（如答案集合的召回奖励）与显式的停止/去重机制，专门改善多答案场景的完整性表现。
5. **更广泛的任务验证**：将框架推广到临床试验匹配、基因-疾病关联发现、药物相互作用预测等更广泛的生物医学 QA 与证据推理任务，并探索跨语言生物医学数据的适用性。

总体而言，SSE-Bio 为生物医学多跳问答中的可控检索与细粒度记忆演化提供了一个设计清晰、实验扎实的解决方案。尽管在检索器能力、模板长期维护和可复现性方面仍有改进空间，但其"结构化状态 + 字段级编辑 + 决策对比训练"的框架思路，对更广泛的智能体检索策略学习与记忆管理研究具有借鉴价值。
