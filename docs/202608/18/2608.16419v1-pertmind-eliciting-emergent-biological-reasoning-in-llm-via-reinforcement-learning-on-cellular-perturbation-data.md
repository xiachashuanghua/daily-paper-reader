## 摘要
大语言模型能够描述机制，但可扩展的后训练仍依赖于昂贵且人工整理的生物推理轨迹。在此，我们表明细胞扰动图谱可以转而成为强化学习环境，其中测得的基因响应为生物推理提供可计算的奖励。我们提出了PertMind，它将可信轨迹监督初始化与基因、通路和格式级别的强化信号相结合。仅通过前向扰动-响应预测训练，PertMind在未见细胞情境中提升了响应推断能力，同时保留了通用语言能力。它还无需任务特定后训练即可迁移至反向扰动识别、双重扰动推理、表型筛选优先排序和生物过程解释。PertMind进一步生成了支持跨多尺度下游任务中具有竞争力的基因、细胞和供体表征的生物特征。这些结果支持了以下假设：对实验终点的强化可以集中预训练模型已可访问的可重用生物策略。更广泛地说，扰动衍生的强化学习为将不断扩展的实验图谱转化为通用生物推理的训练环境提供了一条可扩展的途径。

## Abstract
Large language models can describe mechanisms, yet scalable post-training still depends on costly, manually curated biological reasoning traces. Here we show that cellular perturbation atlases can instead become reinforcement-learning environments, where measured gene responses provide computable rewards for biological reasoning. We introduce PertMind, which combines trusted-trajectory supervised initialization with gene-, pathway-, and format-level reinforcement signals. Trained only on forward perturbation-response prediction, PertMind improved response inference in unseen cellular contexts while retaining general language capabilities. It also transferred without task-specific post-training to reverse perturbation identification, double-perturbation reasoning, phenotypic-screen prioritization, and biological-process interpretation. PertMind further generated biological profiles that supported competitive gene, cell, and donor representations across multiscale downstream tasks. These results support the hypothesis that reinforcement on experimental endpoints can concentrate reusable biological strategies already accessible to pretrained models. More broadly, perturbation-derived reinforcement learning offers a scalable route for transforming expanding experimental atlases into training environments for general-purpose biological reasoning.

## 二、论文提出的方法论

### 2.1 任务定义

- 查询（query）表示为三元组 x = (c, d, g)，其中 c 为细胞系、d 为小分子扰动、g 为靶基因。
- 标签空间为 Y = {Up, Down, No}，分别表示目标基因显著上调、显著下调或无可信差异表达证据。
- 每个查询伴随一个生物知识上下文 K(x)，由外部知识图谱（PubChem、DrugBank、UniProt、Gene Ontology、Reactome、STRING、CORUM）以及训练分区中分结果分层抽取的支持案例构成。
- 模型策略 πθ 采样一个推理轨迹 z 和最终预测标签 ŷg，即 (z, ŷg) ∼ πθ(· | x, K(x))。

### 2.2 数据构造与标签定义

- 使用 Tahoe-100M 的伪批量差异表达统计（DESeq2 风格），按细胞系做严格分区划分——5 个细胞系（C32、HepG2C3A、HOP62、Hs 766T、PANC-1）全部留作测试，其余细胞系用于开发。
- 标签规则：qc,d,g ≤ 0.05 且 |Δc,d,g| ≥ 0.585（≈ log₂1.5）判定为 Up/Down；|Δc,d,g| < 0.20 且 qc,d,g ≥ 0.50 且 baseMean ≥ 10 判定为 No；其余为 ambiguous 并剔除。
- 每个三元组附带置信度权重 w_conf ∈ [0.1, 1]，根据效应大小、显著性和表达量计算。
- **严格的防泄漏控制**：当前查询的标签、差异表达统计量、通路代理标签、验证集和测试集结果均不进入模型提示。

### 2.3 知识增强的 RL 初始化（SFT 阶段）

- 从 Qwen3-4B Base 出发，对每个训练查询采样 M=8 条候选中轨迹。
- 使用五个验证标准筛选"可信轨迹"：(i) 解析后的最终标签与标签一致；(ii) 输出结构完整且只有一个最终答案；(iii) 不声称访问隐藏表达值或标签；(iv) 引用实体和关系受上下文支持；(v) 具有从扰动靶点到通路再到基因结论的完整推理链。
- 对通过筛选的轨迹进行 1 epoch 的 Balanced Fine-Tuning（BFT）——该方案在 token 层面通过局部窗口置信度动态降权低置信 token，在序列层面增强含困难片段的轨迹权重。
- 得到的 SFT 策略 πθSFT 作为 GRPO 的初始化和固定的 KL 参考。

### 2.4 通路监督的强化学习（GRPO 阶段）

- **三层次奖励结构**：
  - **基因级终点奖励**：R_gene = 1[ŷg = yg]，即最终预测标签是否与实验观测一致（0/1）。
  - **通路级中间奖励**：对每个查询预选最多 3 个包含靶基因的 Reactome 通路（排除靶基因本身），在训练侧计算非靶标成员的通路转录响应代理标签 yP ∈ {Up, Down, No, uncertain}；模型需对每个候选通路声明方向，奖励只对被判定为确定（非 uncertain）的通路计算平均匹配率。
  - **格式奖励**：R_fmt 验证输出是否包含所有必需字段、所用标签是否在合法词表内、是否恰好解析出一个终端答案。
- **总奖励**：R(oi) = R_gene(oi) + λpw·mpw·Rpw(oi) + λfmt·Rfmt(oi)，其中 λpw=0.15、λfmt=0.05，且约束 λpw + λfmt < 1，保证辅助奖励永远无法压过一个正确的基因标签。
- **GRPO 优化**：组内标准化优势 Âi = (R(oi) − mean_j R(oj)) / (std_j R(oj) + ε)；使用截断的重要性采样代理和向冻结 SFT 参考的采样 token KL 惩罚；每个三元组的置信度权重 w_conf 作为整组目标函数的统一缩放因子。

## 六、论文的主要结论与发现

1. **前向响应预测提升**：PertMind（4B 参数）在 VCWorld 基准上匹配或小幅超越 Gemini-2.5-Flash 驱动的闭源参考系统，且在多数保持细胞系设置中优于参考。
2. **组件归因清晰**：SFT 提供第一大增益；基因级奖励带来小幅额外提升；仅增加通路文本不提升性能；通路打乱显著降低性能——说明路径奖励的增益来自生物对齐的信号而非额外奖励密度或输出结构。
3. **通用能力保留**：MMLU/CMMLU 上 PertMind 与 Base、SFT 接近，仅小幅下降，未观察到灾难性遗忘。
4. **反向任务迁移**：PertMind 无需反向任务后训练即接近任务专用模型 CellNavi 的性能，且扰动级表现更平坦、稳健；双扰动推理中改善了第二基因的排名，减少了两目标间的不平衡。
5. **表型筛选迁移**：PertMind 生成的筛选特异性生物学简报提升了三个前沿排名骨干在全部五个表型类别上的 AnDCG@100。
6. **过程命名迁移**：PertMind 增强同时提升了 ROUGE 词汇一致性和 MedCPT 语义一致性。
7. **多尺度表示**：PertMind 生成的基因文本描述编码后经表达式加权和注意力聚合，在分子、细胞和供体三个尺度上均展现具有竞争力的表征性能。

## 七、优点

### 7.1 方法层面

- **奖励接口设计精巧**：将实验实测端点和通路转录响应代理转化为无需人工标注的可计算奖励，使训练环境随图谱规模扩展而非随人工标注扩展。
- **严格防泄漏控制**：按细胞系分区、当前查询信息完全隔离在奖励侧、检索仅限训练分区——实验设计对数据泄漏风险高度敏感。
- **独特的通路监督机制**：通路奖励不要求基因响应与通路方向一致（考虑到负反馈和代偿机制），在提供中间结构信号的同时保留生物学灵活性；且通路候选选择完全基于结果无关证据。
- **奖励层级约束合理**：λpw + λfmt < 1 的数学约束保证了辅助奖励在任何情况下不能压过终端基因正确性。
- **消融设计有判别力**：shuffle 对照（打乱通路标签）能有效区分"奖励密度增益"和"生物对齐增益"。

### 7.2 实验层面

- **任务迁移谱系广泛**：从方向预测到排名任务、命名任务、连续表征任务，验证了训练策略的可复用性而非单一任务过拟合。
- **多尺度表征验证**：从基因文本描述到细胞再到供体的分层表征链路设计完整，且包含低参考供体规模的鲁棒性测试。
- **黑盒模型增强**：通过自然语言 brief 增强不可微分的闭源模型，证明了知识的外部化接口价值。

## 八、不足与局限

### 8.1 方法层面

- **终端奖励可能存在捷径**：模型可能学习预测正确端点而无须重构真实生物机制；自由文本轨迹的可审计性不保证其因果忠实性。
- **通路监督是转录代理**：基于注释成员的协调表达，不直接测量蛋白质活性、代谢通量、空间信号或因果通路激活；基于 Reactome 注释的通路成员本身可能包含偏差。
- **候选通路上限为 3 且仅限 Reactome**：可能遗漏其他重要通路资源或更复杂的多通路交互。
- **LoRA 参数高效微调的容量限制**：4B 模型 + LoRA 可能无法充分表达某些复杂推理模式。

### 8.2 实验层面

- **生物多样性覆盖有限**：评估仅覆盖 5 个保持细胞系和有限的组织类型、扰动类别，未涵盖疾病状态、不同剂量时间动态、非转录组模态。
- **算力信息披露不足**：未明确报告 GPU 型号、数量、训练成本，影响可复现性和资源预估。
- **部分面板缺乏误差棒**：如消融图（Figure 3b）不显示运行级不确定性。
- **表示的自适应性**：PertMind 生成的嵌入需要任务特定投影和下游监督，不构成独立于任务的通用固定表示。
- **检索资源的历史偏差**：知识图谱和模型生成的可信轨迹可能传播对高研究力度基因、药物、通路的偏向。

### 8.3 概念层面

- **"涌现"的操作化定义**：论文将"涌现"定义为训练后任务上出现的能力，但这更多是任务迁移，而非认知意义上的能力突现；论文也坦承这一点。
- **忠实性未被充分验证**：模型生成的推理文本虽经过筛选，但没有任何机制保证文本推理链与模型内部计算一致；文献审计仅证明文本中引用的科学联系有文献支持，不证明推理过程是忠实的。

## 结语

PertMind 的核心贡献在于演示了一条**以实验数据为锚、以强化学习为驱动、以预训练知识为基础**的可扩展生物推理训练路线。它将"昂贵的推理轨迹标注"替换为"自动可计算的实验端点"，并在广泛的下游任务中验证了训练策略的可迁移性。这一范式对生物大模型后训练具有参考价值，但其机制忠实性、生物学覆盖范围和计算资源透明度仍留有改进空间。
