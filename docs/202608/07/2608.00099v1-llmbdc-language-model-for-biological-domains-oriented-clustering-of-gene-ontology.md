## 摘要

## Abstract
Gene Ontology (GO) enrichment analysis is a foundational tool for translating large-scale genomic data into biological insights, but typically yields hundreds of redundant terms that obscure overarching themes. Existing summarization tools rely on fixed similarity metrics (REVIGO, GOSemSim, clusterProfiler::simplify()), gene-overlap measures (Metascape), or static hierarchy mappings (GO-slim), and therefore cannot incorporate biological context. Manual curation provides context-aware grouping but is subjective and labor-intensive. A scalable, context-aware framework is needed to cluster GO terms into interpretable higher-order biological domains. Here we present LLMBDC (Large Language Model for Biological Domains Oriented Clustering of Gene Ontology), a training-free framework that leverages zero-shot semantic reasoning of LLMs with confidence scoring to cluster GO terms into BioDomains using only ontology information at inference time. Benchmarked across Alzheimer's disease (AD) and Fragile X syndrome (FXS) against six baseline methods including SapBERT, LLMBDC achieved substantially higher precision, recall, and clustering performance. Against ground-truth annotations, LLMBDC improved ARI from 9.7% to 73.3% (AD) and from 15.7% to 66.6% (FXS) over REVIGO, with corresponding NMI gains from 59.9% to 73.4% (AD) and 66.0% to 79.5% (FXS). A Cauchy combination test further confirmed that aggregated BioDomains retained statistically significant functional signals. LLMBDC provides a scalable, reproducible, and interpretable route to context-aware, system-level interpretation of GO enrichment results while preserving biological specificity.

## 2. 论文提出的方法论

**核心思想：**
- 将GO-to-BioDomain注释任务转化为一个**文本语义排序问题**：对于每个GO术语，从用户定义的候选BioDomain列表中返回最合适的Top-K排序标签。
- 利用LLM的零样本推理能力，**无需任何训练或微调**（训练免费框架），仅依靠LLM预训练时积累的生物医学知识与提示中包含的任务描述完成预测。
- 整个过程包括自适应提示生成 → 零样本LLM查询 → 输出解析 → 域级统计聚合四个步骤。

**关键技术细节：**

**(a) 问题形式化定义（定义3.1）**
- 给定本体论（如GO）中的术语 $t_i$ 和用户指定的生物学领域列表 $D = \{d_1, d_2, \ldots, d_{|D|}\}$，目标是为 $t_i$ 分配最合适的领域标签 $(\hat{d}_1, \hat{d}_2, \ldots)$。

**(b) LLMBDC模型框架**
- 模型 $f_\theta(\cdot)$ 将聚类视为排序任务：$(\hat{d}_1, \hat{d}_2, \ldots, \hat{d}_k) = f_\theta(t, D)$，其中模型参数 $\theta$ 来自公开的预训练模型权重，无需额外微调。

**(c) 自适应提示生成（Adaptive Prompt Generation）**
- 提示生成函数 $\mathfrak{P} = \Psi(t, D)$ 基于模板实现，包含四个核心部分：
  1. **系统提示**：激活LLM的领域知识（如“你是具有GO、通路富集和生物学领域分类专业知识的生物医学本体论专家”）。
  2. **任务介绍**：要求LLM基于GO术语名称和功能上下文，从BioDomain列表中选出Top-5最合适的标签并按相关性排序。
  3. **GO术语信息**：提供GO术语名称和定义。
  4. **可选上下文输入**：包括疾病描述、GO结构、基因集相似性等（经实验验证，添加这些内容并未提升性能）。
- 关键超参数 Top_k 默认设为5。

**(d) 零样本聚类**
- 查询指令微调的LLM生成排序列表：$W = LLM_\vartheta(\Psi(t, D))$，使用冻结参数 $\vartheta$，完全零样本。

**(e) 输出解析（LLM Output Parsing）**
- 通过解析函数 $\Phi(\cdot)$ 将LLM的原始文本输出转换为结构化排序列表：$(\hat{d}_1, \ldots, \hat{d}_k) = \Phi(W)$。
- 提示中包含JSON式输出格式指令以提高解析可靠性，若输出非结构化则采用关键词匹配和文本归一化的备选规则。

**(f) 域级统计聚合**
- 使用**Cauchy组合检验（CCT）** 将簇内各GO术语的p值聚合为域级p值，无需假设术语间相互独立：
  - $T_j = \sum_{i=1}^{n} \tan\{(0.5 - p_i)\pi\}$
  - $P_j = \frac{1}{2} - \frac{1}{\pi}\arctan(T_j)$
- 该方法适用于任意依赖结构下的p值组合，能稳健地生成单个簇级富集p值。

**（g）推荐的最佳实践配置（来自消融实验）：**
- 使用DeepSeek-reasoner模型、低解码温度（0.0–0.1）、禁用“Unknown”标签选项、提示中仅包含GO术语名称与定义。

   - FXS数据集：ARI从15.7%提升至66.6%；NMI从66.0%提升至79.5%；覆盖率从37%提升至100%。

3. **域级富集信号与专家注释高度一致**：CCT聚合p值的排名对比显示，在AD中“线粒体代谢”和“突触”在专家和LLMBDC中均为前两名；在FXS中“免疫系统与炎症”“结构稳定化”“神经传递与突触调控”等领域排名高度吻合，证明LLMBDC无需人工输入即可恢复专家级领域优先级排序。

4. **模型选择对性能有显著影响**：DeepSeek-reasoner在两个数据集上均为最佳（AD：P@1=83.87%；FXS：P@1=78.41%），显著优于ChatGPT-4o-mini和开源模型Qwen3系列；模型规模是关键因素（Qwen3-8B远超Qwen3-0.6B）。

5. **最佳配置可操作性强**：建议使用DeepSeek-reasoner、低温（0.0–0.1）、禁用“Unknown”标签、仅使用GO名称与定义作为提示输入，可获得最优性能；添加额外上下文（疾病描述、GO结构、基因集信息）反而降低性能。

6. **上下文感知的可行性**：LLM能够仅通过自然语言推理这一路径，实现传统方法无法做到的、基于用户自定义领域列表的灵活聚类，同时保持可解释性和统计显著性。

## 7. 优点

1. **真正意义上的“训练免费”（training-free）** ：无需微调或训练，直接利用冻结的预训练LLM完成复杂生物信息学聚类任务，避免了监督数据稀缺的瓶颈，极大降低了应用门槛。
2. **上下文感知与高度可定制**：支持用户自定义BioDomain列表，可灵活融入疾病描述、研究主题等上下文信息，弥补了REVIGO等固定算法无法适配研究特定背景的短板。
3. **可扩展性和适应性**：不依赖固定本体结构或静态层级映射，能够无缝适应GO数据库的持续更新（新增项、定义修订、废弃项移除），且一次可处理数千个GO术语（AD数据集处理了7,120个），

5. **与领域专家注释的可比性**：在域级p值排序上，LLMBDC输出与专家注释高度吻合（AD“线粒体代谢”“突触”均列前二），表明其不仅能生成文本语义合理的簇，还能恢复具有统计显著性的生物学优先级，而非仅做表面字符串匹配。
6. **工程设计细节友好**：通过JSON格式指令、温度控制、备选解析规则等手段，LLMBDC在工程实现上简洁稳健，提示词模板清晰，便于复现与扩展。

## 8. 缺点与局限性

1. **依赖LLM的领域知识与提示质量**：LLMBDC完全依赖LLM在预训练阶段积累的生物医学知识。对于罕见疾病、新兴术语或模型训练截止日期之后新增的GO条目，其性能可能下降；同时提示模板中对任务描述、候选列表顺序等细节较敏感，可能导致结果波动。
2. **推理成本与时延较高**：LLMBDC需要对每个GO术语逐一查询LLM，AD数据集上7,120个术语产生的推理开销不可忽略。论文也承认DeepSeek-reasoner虽然精度更高，但token消耗、运行时间和计算成本均高于GPT-4o-mini等轻量模型，难以满足超大规模（如全基因组富集分析）的即时分析需求。
3. **实验基准的公平性存疑**：LLMBDC在实验1中直接使用专家定义的BioDomain列表作为候选标签，而多数基线方法无法利用该信息；实验2虽设置REVIGO为“未知列表”条件，但LLMBDC的提示中仍含领域列表，两种设定下的对比并不完全对等。此外，论文缺少与`clusterProfiler::simplify()`、GOSemSim、Metascape和GO-slim的直接实验对比，基线覆盖面仍显不足。
4. **数据集规模与领域多样性有限**：两个基准数据集均来自神经相关疾病（AD与FXS），即使病因路径不同，仍无法充分证明方法在癌症、代谢疾病、微生物组等其他生物学领域的泛化性。FXS数据集仅516个GO术语，规模较小，结论的统计效力有限。
5. **未完全解决“语义漂移”与本体结构利用问题**：论文提示GO结构、基因集相似性等额外输入未能提升性能，但未深入分析原因；同时LLM对GO层级关系（is_a / part_of）的隐式利用程度不明，缺乏对术语语义漂移（同一标签对应不同生物语境）的显式处理机制。
6. **可解释性局限于LLM推理过程**：尽管输出了Top-K排序，但排序依据（为什么不选其他候选域）缺乏可量化的解释，属于黑箱决策，对需要严格审计的生物医学应用可能存在障碍。

## 9. 关键相关工作与引文背景

论文将所提方法放在三条技术脉络的交汇处：

1. **GO富集结果简化的经典工具链**：REVIGO（基于语义相似度聚类）、GOSemSim、clusterProfiler::simplify()等，均依赖预定义相似度度量或固定层级，缺乏上下文灵活性。
2. **基于基因集重叠的方法**：Metascape采取从基因集层面聚合相似GO术语的策略，但领域泛化能力较弱，且输出碎片化问题仍未根除。
3. **语义嵌入与静态映射方法**：SapBERT为代表的生物医学概念嵌入模型，以及GO-slim类静态层级映射，分别存在语义粒度粗糙和无法动态适应数据更新的问题。

LLMBDC则明确将这些方法视为“固定先验的静态聚类”，将“用户自定义语义空间中的排序”作为新范式，从而在相关工作层面与既有工具划清界限。此外，论文在CCT聚合部分引用了Cauchy组合检验的统计学文献，为域级p值聚合提供了理论支撑。

## 10. 个人评价与总体判断

**总体判断**：LLMBDC是一篇方法新颖、实验扎实、工程友好的高质量生物信息学方法论文。其最大贡献并非仅仅是“用LLM做聚类”这一表面创新，而在于将功能富集分析的核心痛点——从“统计显著的术语列表”到“生物学可解释的领域”的跨越——重新定义为可由LLM零样本完成的排序任务，从而开辟了一条摆脱监督数据、本体结构和人工标注的注释路径。

**亮点突出**：
- 训练免费设计解决了生物信息学中监督数据稀缺的长期瓶颈；
- 用户自定义BioDomain列表的机制天然支持上下文感知，这是所有经典工具无法企及的；
- 对温度、“Unknown”标签、提示内容等超参数的消融研究极其细致，工程落地价值高。

**明显不足**：
- 实验公平性存在固有不对称（LLMBDC使用领域列表，基线未使用），部分削弱了对比结论的绝对说服力；
- 两个神经疾病数据集不足以支撑“通用生物学领域”的普适性声明；
- 对推理成本和时延的讨论停留在定性层面，缺少量化的资源消耗数据（如API调用次数、延迟、token数）。

**未来方向展望**（论文未深入讨论但可合理推导）：
- 将LLMBDC扩展到KEGG、Reactome等通路本体，检验跨本体泛化；
- 引入批量提示或缓存机制以降低推理成本；
- 将LLM排序结果与GO结构信息做后处理融合，弥补纯语义排序对层级关系的忽视；
- 探索更小参数量蒸馏模型的部署，降低对商业API的依赖。

综合来看，LLMBDC在方法论上具有鲜明的原创性和示范价值，为LLM驱动的功能基因组学分析提供了一个有力的新范式。尽管在基准公平性和领域普适性上仍有改进空间，但作为一篇提出新任务形式化、验证可行性的方法论文，其贡献扎实、可复现性强，值得领域内研究者关注与扩展。
