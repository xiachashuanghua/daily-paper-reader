## 摘要
CASCADE是一个智能体框架，通过MCP从预计算的ARACNe调控网络预测基因扰动的下游转录效应。先前的工作通过检查预测基因是否为已知癌症基因（成员关系）来验证此类工具；我们则通过使用焦点基因拷贝数扩增作为敲低的剂量代理（反向），针对真实TCGA患者肿瘤数据，检验预测的变化方向是否与现实一致。对于MYC，CASCADE预测的敲低靶标在三种癌症类型（BRCA：90.0%，COAD：72.0%，STAD：85.7%；所有p<0.0013）中与真实扩增与非扩增肿瘤表达高度一致，显著高于排列基线，并通过PAM50亚型对照，且在独立队列（METABRIC，87.2%）中重复。与基于MSigDB基因集的精选基线通过Fisher精确检验比较，CASCADE的准确性未显示超过现有关于MYC或E2F驱动生物学的公共知识，但其基因特异性方向判定明显优于朴素均匀猜测。扩展到另外十五个基因后，验证证明是基因特异性的而非通用性的：增殖机制调控因子大多可重复，而谱系同一性转录因子和一个细胞周期蛋白D旁系同源物（CCND2）始终失败，我们将这一模式讨论为有对冲的事后假设。我们单独基准测试了基于LLM的智能体是否将自然语言请求正确映射到CASCADE的真实MCP工具调用中。在35个查询中，一个有记录的小型本地模型达到71.4%的精确匹配（较大模型为85.7%）；模式和基因别名失败可通过规模或服务器端修正解决，但两个模型在模糊查询上都自信地默认选用错误的扰动类型，这一失败无法通过针对性修复解决，因为其触发条件从未出现。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

- **研究背景**：基因扰动（敲低/过表达）的下游转录效应预测是癌症系统生物学的核心任务，可用于机制假说与治疗靶点优先排序。当前基于调控网络的工具能够以极低成本生成此类预测，但验证方式存在根本缺口。

- **整体含义**：论文提出 CASCADE，一个基于智能体的调控网络框架，其核心贡献是**用真实患者肿瘤数据对工具所声明的具体方向性预测进行直接验证**，而非仅凭网络拓扑或基因集成员推断其合理性。这是一种更严格、更贴近真实临床情境的验证范式。

## 二、方法论

### 2.1 体系结构

- CASCADE 是一个 Python 包，通过 **LangGraph 编排工作流** + **MCP（Model Context Protocol）** 暴露基因扰动分析能力。
- 工作流核心流程：焦点基因 → 基因角色分类（决定路由路径）→ 并发批量调度 → 信号传播 → 生成预测靶标列表。
- 论文中的实验均直接调用 `CascadeWorkflow.run()`，参数包括 `gene`、`perturbation_type`、`analysis_depth="focused"`、`network_source="tcga"`、`tcga_network`、`top_k=50`。
- 用户通过经验性验证而非仅阅读路由代码，确认对于本论文测试的所有基因角色，"focused" 深度恰好触发 `{perturbation, targets}` 两个核心分析，且仅提取 `perturbation_effects` 字段用于统计分析。

### 2.2 信号传播算法

- 网络组件：确定性广度优先算法，沿 ARACNe 网络的有向调控边传播。
  - 敲低时焦点基因初始效应为 −1.0；
  - 每跳传播到靶基因的效应为父基因当前效应 × 边权重 × **衰减因子 0.5**，沿路径累加；
  - 边权重由 ARACNe 互信息量级按作用模式注释（激活边保持符号，抑制边翻转符号）签名——**符号翻转是产生上/下方向预测的主要机制**。
- 嵌入组件：叠加 GREmLN 预测的基因嵌入余弦相似度加权贡献（α = 0.7），可增添经由嵌入相似性而非网络传播可达的候选基因，但不会翻转网络可达基因的方向。
- 默认传播深度为 **2 跳**，默认结果大小为 **top 25**（验证实验显式指定 top 50）。

### 2.3 方向一致性验证方法

- 以**焦点基因拷贝数扩增**（GISTIC 离散值 = 2）作为增加焦点基因活性的剂量代理——即敲低的**反向**。
- 对每个预测靶基因，比较扩增与非扩增（GISTIC = 0）患者样本间的平均 mRNA 表达 z-score：
  - 预测敲低后下调的基因（即被焦点基因正调控），若在扩增样本中表达更高，则记为一致；
  - 预测上调的基因（负调控），若在扩增样本中表达更低，则记为一致。
- 任意一组样本数 <10 的基因被排除。
- 显著性评估：单尾二项检验（零假设：一致性率 = 0.5）+ 独立置换控制（1000 次从 200 个随机网络基因的背景池中抽取，排除焦点基因和 CASCADE 自身的预测集，随机分配与真实预测方向比例匹配的方向标签），置换经验 p 值为达到或超过观测一致性率的置换比例。

### 2.4 基因面板选择

- 候选基因需满足两项独立标准：(i) 网络出度 ≥25；(ii) 相应 cBioPortal 数据集中 GISTIC 扩增样本 ≥15–20。
- 筛选过程本身即是一个发现：**跨组织、可与 MYC 媲美的强扩增驱动效应在转录因子中极为稀少**，这约束了泛化面板的规模上限。

### 2.5 LLM 工具调用接地评估

- 35 条人工标注的自然语言查询，覆盖 7 个类别（每类 5 条）：TCGA 基线、免疫细胞基线、基因别名、非正式/全称癌症名、非规范扰动措辞、隐式参数、多实体干扰项。
- 两个本地模型通过 Ollama 测试：`llama3.1:8b`（CASCADE 文档默认部署配置）与 `qwen2.5:72b`（更大的次级对比模型）。
- 基因别名查询双重计分：原始工具调用输出 vs. 经 CASCADE 真实 `resolve_alias()` 步骤（MCP 服务器在任何网络查找前运行的同一处理）。

## 六、主要结论与发现

1. **MYC 方向预测在真实患者数据中高一致性**：BRCA 90.0%（p < 10⁻⁸）、COAD 72.0%（p = 0.0013）、STAD 85.7%（p < 0.0001），全部远超置换基线（48–54%），置换经验 p = 0.0000。
2. **一致性结果在混淆控制与独立队列中稳健**：PAM50 Luminal B 亚型内 92.0%；METABRIC 独立队列 87.2%（p < 10⁻⁶），排除了共享数据来源假象。
3. **一致性基因集具有生物学合理性**：BRCA 中最高一致基因包括 NOP14、NOB1、RIOK1、NOLC1、WDR43、KAT2A 等——核糖体生物合成/核仁机制组分正是 MYC 在癌症生物学中公认的转录程序。
4. **CASCADE 未显著超越现有公共知识**：与 MSigDB 精选基因集的 4 组对比均不显著（BH-FDR q = 0.767–0.863），但其基因特异性方向判定显著优于朴素均匀猜测（强制"下调"导致一致性下降 14–29 个百分点）。
5. **验证是基因特异性的，而非普遍性的**：10 个增殖机制基因中 9 个在某些癌症类型中验证成功；5 个谱系同一性/RTK 基因作为类别全部失败（GATA3 完全反一致 0/50，ESR1 仅 4.0%）；CCND2 是唯一在所有测试癌症类型中均失败的增殖机制基因，尽管与其验证成功的旁系同源基因（CCND1、CCND3）资格条件相同。
6. **癌症类型背景同样影响验证结果**：CCND1 与 MDM2 在 BRCA 中验证成功但 STAD 中失败；ERBB2 在 BRCA 和 COAD 中强反一致（18.0%、14.3%）但在 STAD 中强一致（93.6%）。
7. **LLM 工具调用接地可靠性与模型规模相关，且存在不可解析的失败模式**：llama3.1:8b 精确匹配 71.4%，qwen2.5:72b 为 85.7%；模式违背（schema 错误）随模型规模完全解决；基因别名经服务器端 `resolve_alias()` 后全部解决（提升至 77.1%/94.3%）；但**两个模型在模糊查询上都自信地默认选择错误的扰动类型**（"What does MYC do?" 均选了过表达而非文档默认的敲低），且针对性修复无效——因为模型总是给出一个具体值而非留空，触发条件从未出现。

## 七、优点

- **验证范式升级**：将验证对象从"预测基因是否已知癌症基因"（成员关系）升级为"预测方向是否与现实一致"（方向一致性），直接检验智能体在 MCP 工具调用中真正会向用户重复的声明。
- **多重稳健性设计**：二项检验 + 置换控制（排除基因集结构假象）+ 面板大小敏感性 + PAM50 混淆控制 + 独立无重叠队列复制，构成严密的多层验证。
- **反事实检验**：通过在三个不同方向上的消融（均匀猜测、嵌入移除、方向强制）证明 CASCADE 的基因特异性推理确实在起作用。
- **诚实的失败报告**：完整披露未通过验证的基因（包括完全反一致的 GATA3、预测会失败的 ESR1），不回避反例；基因选择来源全程透明；CCND2 作为最尖锐的反例被醒目呈现。
- **端到端验证思维**：不仅验证预测准确性，还单独评估"自然语言 → 工具参数"这一上游环节——这是一般工具论文忽略的关键中介步骤。
- **代码与数据完全公开**：脚本、输出、网络文件、全部数据源均公开，可复现性强。

## 八、不足与局限
