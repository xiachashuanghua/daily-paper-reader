## 摘要
大语言模型（LLM）通过指令遵循和上下文学习，在生物医学命名实体识别（BioNER）中展现出良好潜力。然而，现有基于 LLM 的 BioNER 方法仍面临两个关键局限。首先，检索到的示例和外部生物医学知识对数据集特定的标注语义支持有限，导致实体边界、类型范围和标注约定仍不明确。其次，自由形式生成缺乏足够的结构控制，常导致格式无效、提及幻觉、实体重复和边界错误。为解决这些局限，我们提出 GAMA，一种面向模式即代码 BioNER 的指南增强多智能体框架。GAMA 首先从有标注的训练实例中归纳候选标注规则，并依据标注数据对其进行验证，以构建可靠的数据集特定指南记忆。在这些经过验证的规则指导下，规划组件生成带有理由的排序跨度-类型假设，编码组件将其转换为受模式约束的实体对象。随后，验证模块检查跨度接地、类型有效性和结构合规性，并执行双循环细化以纠正无效或低置信度的预测。在五个广泛使用的 BioNER 数据集上、使用多种 LLM 主干模型的实验表明，GAMA 始终优于强大的基于 LLM 的基线方法。消融实验和参数分析进一步验证了所提出组件的有效性。

## Abstract
Large language models (LLMs) have shown promising potential for biomedical named entity recognition (BioNER) through instruction following and in-context learning. However, existing LLM-based BioNER methods still face two key limitations. First, retrieved demonstrations and external biomedical knowledge provide limited support for dataset-specific annotation semantics, leaving entity boundaries, type scopes, and annotation conventions ambiguous. Second, free-form generation lacks sufficient structural control, often leading to invalid formats, hallucinated mentions, duplicated entities, and boundary errors. To address these limitations, we propose GAMA, a guideline-augmented multi-agent framework for schema-as-code BioNER. GAMA first induces candidate annotation rules from labeled training instances and verifies them against annotated data to construct reliable dataset-specific guideline memory. Guided by these verified rules, a planning component generates ranked span-type hypotheses with rationales, and a coding component converts them into schema-constrained entity objects. A verification module then checks span grounding, type validity, and structural compliance, and performs dual-loop refinement to correct invalid or low-confidence predictions. Experiments on five widely used BioNER datasets with multiple LLM backbones show that GAMA consistently outperforms strong LLM-based baselines. Ablation and parameter analyses further verify the effectiveness of the proposed components.

## 2. 论文提出的方法论

### 2.1 核心思想

GAMA 的核心思想包括三点：

- **显式指南建模**：从训练实例中归纳数据集特定标注规则，并通过训练数据验证过滤，构建可复用的指南记忆。
- **多智能体分解**：将抽取过程拆分为规则归纳、规则验证、规划、编码、验证与双环修正五个专门组件。
- **模式即代码验证**：把实体预测表示为受 schema 约束的实体对象，并检查跨度接地、类型有效性和结构合规性。

### 2.2 五阶段流程

- **标注规则归纳 Agent**：
  - 给定数据集 \(s\) 的训练集 \(D(s)=\{(x_i,y_i)\}\)，其中 \(y_i\) 包含实体提及与类型。
  - 对每个训练实例生成候选规则集合 \(R_i^{(s)}\)，并汇总为全局候选规则池 \(R^{(s)}\)。
  - 目的是把实例级标注转化为显式的数据集级标注规则。

- **规则验证与指南记忆构建 Agent**：
  - 对每条候选规则 \(r_k\)，将其应用于训练实例，生成规则引导预测 \(\hat{y}_{i,k}^{(s)}\)。
  - 若规则能帮助恢复至少一个金实体，且提及边界和实体类型正确，则该实例支持该规则。
  - 统计规则支持分数，丢弃零支持规则，按实体类型分组排序，每类保留 Top-N 规则，构建指南记忆 \(G^{(s)}\)。
  - 论文设置 \(N=10\)。

- **指南引导的提及规划 Agent**：
  - 输入句子 \(x\)、指南记忆 \(G^{(s)}\) 和实体 schema \(S^{(s)}\)。
  - 生成排序的候选假设集合 \(P=\{(m_i,t_i,\beta_i,\rho_i)\}_{i=1}^{K}\)。
  - 其中 \(m_i\) 为候选提及，\(t_i\) 为实体类型，\(\beta_i\) 为置信度，\(\rho_i\) 为基于指南的自然语言理由。
  - 论文设置 \(K=3\)，即生成 3 个排序候选。

- **模式即代码实体构建 Agent**：
  - 将规划假设转为受 schema 约束的实体对象：\(c_i=\text{EntityObject}(m_i,t_i)\)。
  - 对象包含 `span` 和 `entity_type` 字段，类型受数据集类型集合 \(T^{(s)}\) 约束。
  - 保留 \(\beta_i\) 和 \(\rho_i\) 作为辅助信息，供后续验证和冲突处理。

- **验证与双环修正模块**：
  - 对每个实体对象 \(c_i\)，检查三个维度：
    - 跨度接地：提及是否出现在原句中；
    - 类型有效性：类型是否属于 \(T^{(s)}\)；
    - 结构合规：对象是否符合 schema。
  - 形式化表示为 \((V_i,\epsilon_i)=V_{\text{pred}}(c_i,x,S^{(s)})\)，其中 \(V_i\) 表示是否通过，\(\epsilon_i\) 为诊断反馈。
  - 双环修正：
    - 外环按规划置信度 \(\beta_i\) 优先处理高置信候选；
    - 内环根据诊断反馈 \(\epsilon_i\) 修正并重新检查，直到通过或达到最大迭代次数。
  - 论文设置最大内环迭代次数 \(t=3\)。
  - 最终预测集合为通过验证的 \((m_i,t_i)\)。
