## 摘要
基因集分析是功能基因组学的基石，但仍需大量人工投入，并高度依赖人工审编和专家生物学解释。尽管大语言模型（LLM）已成为基因组推理与注释的强大工具，但现有方法大多依赖符号化基因名称，未能捕捉领域特有的生物学结构，尤其是决定分子活性、相互作用及下游基因功能的蛋白质序列信息。在本工作中，我们提出 SoftGene，一种利用基因集层级结构的、基于 LLM 的基因集注释新框架。首先，我们使用基于 ESM（一种蛋白质语言模型）构建的层级注意力编码器，利用蛋白质层面的氨基酸序列信息来表示每个基因集。其次，我们构建了一种混合提示方案，将源自基因集嵌入的软提示与包含由 LLM 生成的辅助上下文的硬提示相结合，并将所得提示输入本地 LLM 进行注释。我们在两个基准数据集上评估该框架：基因本体（GO）和分子特征数据库（MSigDB）。结果表明，将蛋白质序列表示与文本上下文相结合总体上提升了基因集注释效果，而分领域分析显示，蛋白质嵌入的贡献因生物学领域而异。

## Abstract
Gene set analysis is a cornerstone of functional genomics, yet it remains labor-intensive and heavily dependent on manual curation and expert biological interpretation. While Large Language Models (LLMs) have emerged as powerful tools for genomic reasoning and annotation, most existing approaches rely on symbolic gene names and fail to capture domain-specific biological structure, particularly protein sequence information that governs molecular activity, interactions, and downstream gene function. In this work, we propose SoftGene, a novel framework for LLM-based gene set annotation that leverages the hierarchical structure of gene sets. First, we use a hierarchical attention-based encoder built on ESM, a protein language model, to represent each gene set using protein-level amino acid sequence information. Second, we construct a hybrid prompting scheme that combines soft prompts derived from gene set embeddings with hard prompts containing auxiliary context generated by an LLM, and feed the resulting prompt into a local LLM for annotation. We evaluate our framework on two benchmark datasets: Gene Ontology (GO) and the Molecular Signatures Database (MSigDB). Our results show that integrating protein-sequence representations with textual context improves gene set annotation overall, while per-domain analyses reveal that the contribution of protein embeddings varies across biological domains.

- **现有 LLM 方法的不足**：
  - 大多把基因当作**符号化 token**，忽略了决定分子活性与相互作用的**蛋白质序列信息**；

- **整体含义**：SoftGene 提出将蛋白质语言模型（PLM）序列表示与 LLM 文本推理相结合的软提示框架，旨在同时提升注释质量与可解释性，为功能基因组学提供序列感知的新范式。

## 2. 方法论

### 核心思想
利用基因集的三层层级结构（基因集 → 基因 → 蛋白亚型），用冻结的蛋白质语言模型编码氨基酸序列，通过可训练的注意力池化逐级聚合，最终映射为软提示 token，与硬提示拼接后驱动本地 LLM 生成注释。

### 关键技术细节

- **问题形式化**：给定基因集 $\mathcal{G}=\{g_1,\dots,g_M\}$，每个基因 $g_i$ 对应若干蛋白亚型 $p_{i,1},\dots,p_{i,K_i}$，每个蛋白是氨基酸序列。目标是学习映射 $f_\theta(\mathcal{G})=\hat{y}\approx y$，即条件序列生成。

- **分层注意力编码器**：
  - **蛋白层**：用冻结的 ESM-2 编码每个氨基酸，得到上下文嵌入 $\hat{a}_k$，再对序列做**平均池化**得到蛋白嵌入 $\hat{p}_j$。
  - **基因层**：对同一基因的多个剪接亚型用 `AttentionPooling` 加权聚合，得到基因嵌入 $\hat{g}_i$，可自动降权噪声亚型。
  - **基因集层**：对集合内所有基因嵌入再次用独立参数的 `AttentionPooling` 聚合，得到基因集表示 $\hat{\mathcal{G}}$。
  - 注意力池化公式：$h_k=\text{MLP}(x_k)$，$\alpha_k=\text{softmax}(h_k)$，$\hat{x}=\sum_k \alpha_k x_k$。

- **混合软提示模块**：
  - 用可训练 MLP 将 $\hat{\mathcal{G}}$ 投影为 $n$ 个软 token：$S=\text{MLP}_{soft}(\hat{\mathcal{G}})\in\mathbb{R}^{n\times d_{LLM}}$。
  - 硬提示包括两部分：任务指令 $H_{inst}$；由商业 LLM（GPT-4.1 Nano）根据基因符号生成的辅助上下文 $H_{cont}$。
  - 最终输入为三者拼接：$\hat{y}=\text{LLM}_{local}([S;H_{inst};H_{cont}])$，本地模型为 Llama 3。

- **训练过程**：采用 teacher forcing，优化 token 级交叉熵损失
  $$\mathcal{L}_{LM}=-\sum_{t=1}^{T}\log P(y_t\mid y_{<t},S,H_{inst},H_{cont})$$
  训练时**冻结 PLM 和 LLM**，梯度只回传到软提示投影器和分层注意力编码器，实现参数高效适配。

- **整体性能提升**：SoftGene 在所有指标和两个数据集上均优于提示工程、提示微调和智能体基线，其中 Llama 3.1 8B 版本表现最佳（GO：METEOR 0.220、ROUGE-L 0.267、BERTScore 0.806）。

- **可解释性有效**：注意力权重与已知生物学知识高度吻合（如锌转运蛋白 SLC39/SLC30、平滑肌中的 PRKG1α 亚型选择），无需亚型级监督即可区分功能性剪接变体。

## 7. 优点

- **方法创新**：首次将 PLM 序列表示通过分层注意力编码后，以软提示形式注入 LLM，桥接生物序列与自然语言。
- **可解释性强**：注意力机制提供基因级和蛋白亚型级的显式特征归因，超越纯 LLM 的隐式推理。
- **参数高效**：冻结 PLM 与 LLM，仅训练注意力池化层和投影器，计算开销可控（O(n) 复杂度，避免二次注意力瓶颈）。
- **鲁棒性好**：对 PLM 骨干（ESM2 系列、ProtBERT）和商业 LLM 上下文生成器（GPT、DeepSeek、Claude）均表现稳定。
- **实验严谨**：包含基因不相交泛化、污染分析、失败模式分析、生物指标验证，评估维度全面。
- **诚实报告**：明确承认生物语义指标上的提升幅度小于词汇指标，未过度宣称。

## 8. 不足与局限

- **数据集偏差**：训练和评估基于人工审编资源（GO、MSigDB），偏向研究充分的基因和过程，对注释稀疏或新兴功能泛化能力有限。
- **评估局限**：主要采用基于参考文本的指标，无法完全反映生物学正确性或实验有效性，缺少专家评估和下游实验验证。
- **域依赖性强**：蛋白序列嵌入的贡献在不同生物域间差异显著，在 BP 域几乎无增益，方法收益不稳定。
- **依赖商业 LLM**：辅助上下文 $H_{cont}$ 依赖 GPT-4.1 Nano 等商业模型，引入网络延迟、成本与可重复性问题；虽声称可替换为本地模型，但未验证完全离线场景。
