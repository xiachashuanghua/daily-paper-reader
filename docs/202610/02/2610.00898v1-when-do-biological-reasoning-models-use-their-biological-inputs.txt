ABSTRACT 

Biological reasoning models use post-training to connect LLMs to biological in-puts, typically representations from a biological foundation model and biological text such as gene and pathway descriptions, functional annotations, and gene lists. Their benchmark accuracy is taken as evidence that the LLM reasons over their biological inputs. We test this assumption in six biological reasoning models across DNA, protein, and single cell tasks. We perturb one biological input while holding the query and other inputs fixed, construct evidence conflicts that pair the founda-tion model representation of one genome, protein, or cell with the text of another, fit linear probes to the representations the language model receives, and analyze reasoning traces against the biological inputs. We find that current post-training strategies do not ensure that foundation model representations contribute to task performance. Evo2 and ESM3 contribute little to BioReason and BioReason-Pro performance on the evaluated tasks. Shuffling the DNA sequence barely changes BioReason disease prediction accuracy, and in evidence conflicts the two models follow the text in 97.9% and 99.7% of cases. Linear probes trained on the Evo2 and ESM3 representations predict the task targets, so these foundation models encode information relevant to the task, but provide limited overall performance improvement to BioReason and BioReason-Pro. In contrast, foundation model inputs contribute to ChatNT, Prot2Text-V2, and CellWhisperer performance, and differentially expressed genes in the gene sentence contribute to Cell2Sentence-Scale performance. Across SFT and RL checkpoints of BioReason-Pro and 42 BioReason checkpoints, increases in accuracy do not imply greater performance contributions from biological inputs. In reasoning traces, BioReason traces mis-state nucleotide changes, while BioReason-Pro traces describe functions omitted from final predictions under evidence conflicts. Future work should test whether post-training objectives that reward correct use of biological inputs improve their contribution to task performance. Recent examples include DNA–LLM models (Fallahpour et al., 2025; de Almeida et al., 2025), single-cell transcriptomic language models (Levine et al., 2024; Schaefer et al., 2025), and protein reasoning models (Queen et al., 2025; Fallahpour et al., 2026; Liu et al., 2024; Su et al., 2026). Benchmark performance alone, however, does not establish which biological inputs drive prediction. Predictive annotations can support accurate answers even when accompanying sequence or transcriptomic representations are underused, so benchmark improvements need not reflect greater use of these representations (Geirhos et al., 2020; DeGrave et al., 2021). Attributing a prediction to a particular biological input is difficult because these models often receive multiple representations of the same protein, genome, or cell. These representations can encode overlapping biological properties at different levels of abstraction. A limited performance contribution from one input may therefore reflect support from another input, limited predictive value of the evaluated input, or limited use of a predictive input by the reasoning model. Benchmark performance alone cannot distinguish among these alternative explanations. Related problems have been studied in vision–language models, where predictions can exploit language priors or remain insensitive to relevant visual content (Goyal et al., 2017; Agrawal et al., 2018; Hessel & Lee, 2020; Asadi et al., 2026). Representation probing has separately shown that a target can be predicted from a learned representation without implying that the model uses that representation for its own prediction (Ravichander et al., 2021; Elazar et al., 2021). Biological reasoning models exacerbate these challenges because several representations derived from the same biological object may be available to the model simultaneously. Existing evaluations of these models emphasize task performance, leaving unresolved which biological inputs contribute to prediction. 

Present work. Biological reasoning models are multimodal LLMs that receive a user task together with biological inputs, such as foundation model representations of a genome, protein, or cell and biological text, and generate a response that contains an answer and often a reasoning trace (Figure 1). We develop tests that determine whether the response of such a model depends on each of its biological inputs. The first test (“Perturbation”) perturbs one biological input while holding the user task and the other inputs fixed and measures changes in the answer and task performance. The second test (“Evidence conflict”) places inputs from two different genomes, proteins, or cells in the same prompt so that they support different answers, and identifies the input the model follows. When an input contributes little to performance, linear probes on the representation the model receives determine whether that input encodes the task target, which separates an uninformative input from an informative input with a limited performance contribution (“Linear probe”). The fourth test (“Reasoning trace”) evaluates whether biological claims in generated traces and prompted rationales agree with the supplied inputs, respond to input perturbations, and remain consistent with final predictions. We apply these tests to six models (Table 1) across post-training checkpoints and model scales. Our main findings are: • Foundation model representations can contribute little to performance even when they encode the task target. BioReason and BioReason-Pro prefer the biological text in evidence conflicts, and Evo2 and ESM3 representations contribute little to their performance, although linear probes predict the task targets from these representations. Foundation model representations contribute to ChatNT, Prot2Text-V2, and CellWhisperer performance, and differentially expressed genes (DEGs) in the gene sentence contribute to C2S-Scale performance. 2• Higher accuracy after post-training does not indicate a greater performance contribution from the foundation model. SFT and RL increase the accuracy of BioReason and BioReason-Pro without increasing the performance contribution from Evo2 and ESM3 representations, and we observe the same result across 42 BioReason checkpoints. Scaling C2S-Scale from 2B to 27B increases accuracy and the performance contribution from DEGs. • Generated reasoning does not consistently connect biological evidence to final predictions. 

BioReason makes incorrect claims about nucleotide substitutions, while BioReason-Pro discusses functions absent from its final GO annotations under evidence conflicts. For C2S-Scale 27B, marker enrichment is concentrated in the first few gene references and is lost across the full rationale where it over-references ribosomal protein genes. • Auxiliary supervision increases sequence sensitivity, but the edited-base prediction contributes little to disease prediction performance. Training BioReason to predict the edited bases makes this prediction depend on Evo2 representations. Shuffling the sequence lowers accuracy on the edited base pair by 0.549 and disease prediction accuracy by only 0.021. However, this improvement in predicting edited bases is limited to genomes seen during training. 

2 RELATED WORK 

Biological reasoning models. Biological reasoning models differ in their input representations. ChatNT uses Nucleotide Transformer representations, while BioReason combines Evo2 with gene and pathway text (de Almeida et al., 2025; Brixi et al., 2026; Fallahpour et al., 2025). Prot2Text-V2 combines ESM2 representations with protein name and taxon text, whereas BioReason-Pro combines ESM3 with GO-GPT predictions and InterPro annotations (Fei et al., 2025; Hayes et al., 2025; Fallahpour et al., 2026). Cell2Sentence-Scale represents transcriptomes as expression-ranked gene sentences, while CellWhisperer uses continuous transcriptomic representations (Levine et al., 2024; Schaefer et al., 2025). Other protein models connect biological representations with language for retrieval, annotation, or generation (Queen et al., 2025; Su et al., 2026; Xu et al., 2023; Liu et al., 2024; Jararweh et al., 2025; Wang et al., 2024; Char et al., 2025). Evaluations largely emphasize task performance, scale, and post-training (Fesser et al., 2026; Wu et al., 2025; Zhao et al., 2026; He et al., 2025; Dip et al., 2026). We instead test whether predictions depend on biological input content, distinguishing target predictability from model use. 

Multimodal representation learning and evaluation. Multimodal learning literature studies how representations from different modalities can be aligned, combined, and decomposed into shared or modality-specific structure (Liang et al., 2024; Dufumier et al., 2025; Huh et al., 2024; Gupta et al., 2026; Zhang et al., 2026; Richter et al., 2026). Complementary work evaluates whether multimodal models use the inputs provided to them. Vision–language models can exploit language priors, remain insensitive to visual content, or improve benchmark performance without increased cross-modal interaction (Goyal et al., 2017; Agrawal et al., 2018; Cadene et al., 2019; Hessel & Lee, 2020; Frank et al., 2021; Asadi et al., 2026; Gao et al., 2026). Counterfactual inputs and controlled perturbations have therefore been used to test whether predictions respond to the content of a particular modality (Niu et al., 2021; Thrush et al., 2022). Our work focuses on biological reasoning models, where multiple representations of the same protein, genome, or cell may be available simultaneously, and asks which of these biological inputs contribute to the downstream prediction. 

Predictive representations and generated rationales. Linear probes provide a simple test of predictability from learned representations (Alain & Bengio, 2017; Hewitt & Liang, 2019), while subsequent work has shown that probe performance and downstream model behavior should be evaluated separately (Ravichander et al., 2021; Elazar et al., 2021). Generated rationales introduce a related distinction because plausible explanations need not identify the features that affect model predictions (Jacovi & Goldberg, 2020; DeYoung et al., 2020; Wiegreffe et al., 2021; Turpin et al., 2023). We use simple predictive baselines to interpret limited performance contributions from a biological input and compare features that affect prediction with those referenced in generated rationales. 

3 APPROACH 

3.1 PROBLEM FORMULATION 

Biological reasoning models take a text query q, which specifies the task and response format, together with biological inputs Z = ( Zrepr , Ztext ) associated with a biological modality X, such as protein 3sequence, genomic sequence, or a single-cell transcriptome. We distinguish continuous biological representations Zrepr from biological inputs represented as text Ztext . For target y, the model fθ

produces a prediction and, optionally, a rationale or reasoning trace, (ˆ y, ˆR) = fθ (q, Z). We call the full input (q, Z) the prompt, and a task is the set of queries that share one objective and label space, such as disease prediction. Our objective is to determine whether a biological input Zi is used by the model to make its prediction. We test this by changing the task-relevant biological content of Zi while holding q and the remaining inputs Z−i fixed, and measuring prediction sensitivity and changes in task performance. We also test source preference with evidence conflicts , inputs in which two biological evidence sources support different predictions, constructed by combining Zi from one query with one or more inputs in Z−i

from another, and measure which source the prediction follows. When perturbing Zi has little effect on task performance, we additionally test whether the target can be predicted from Zi using a simple predictive baseline, such as a majority-vote lookup or linear probe. Zi is underutilized when it supports prediction of the target with such a baseline, but changing its task-relevant biological content has little effect on the reasoning model’s task performance after controlling for predictive information in Z−i where possible.

3.2 EVALUATION PROTOCOL 

Table 1 summarizes the six models we benchmark, their input sources, model variants, tasks, and evaluation data. We organize our evaluation around four research questions. RQ1: Does task-relevant biological content in a biological input affect the model’s prediction? We perturb the task-relevant biological content of Zi while holding q and Z−i fixed and measure changes in predictions and task performance, and we construct evidence conflicts from unmodified queries to measure source preference. When the perturbation has little effect on performance, we additionally test whether the target can be predicted from Zi using a simple predictive baseline. When possible, we also remove or control other predictive biological inputs before concluding that Zi is underutilized. 

RQ2: Does higher benchmark performance correspond to greater performance contributions from biological inputs? Across model variants that differ in post-training checkpoint or scale, we compare benchmark performance with its change under the same biological perturbations used in RQ1. 4This tests whether improvements in task performance are accompanied by a greater performance contribution from the evaluated biological input. RQ3: Do reasoning traces and generated explanations reflect the supplied biological evidence? We evaluate whether generated responses agree with the biological inputs, and how they change when the biological input is perturbed. For evaluated models that do not produce reasoning traces during prediction, we prompt them to identify the biological evidence supporting their predictions. RQ4: Can auxiliary supervision increase use of a biological input? We add an auxiliary objective that requires the model to predict biological content from Zi and test whether this increases the effect of Zi on the downstream task performance. 

4 RESULTS : B IOLOGICAL INPUT USE IN REASONING MODELS 

4.1 RQ1: F OUNDATION MODEL REPRESENTATIONS CAN CONTRIBUTE LITTLE TO PERFORMANCE EVEN WHEN THEY ENCODE TASK INFORMATION 

Here we test prediction sensitivity, performance contribution, and source preference for the evaluated biological inputs with perturbations of biological inputs while holding the query and remaining inputs fixed, and construction of evidence conflicts from unmodified queries. For inputs with limited performance contributions, we confirm their utility to the task with linear probes to test target predictability. Appendices A and B provide the datasets and experimental setup used. 

Biological perturbations reduce performance in four models but have little effect on per-formance in BioReason and BioReason-Pro. BioReason disease prediction accuracy is almost unchanged with shuffled DNA inputs (0.847 vs. 0.847), although it changes 101 of 1,449 answers (7.0%, Table S2). The largest decrease in accuracy occurs when the gene name is removed (Fig. 2a). For ChatNT, accuracy decreases from 0.988 to 0.502 for splice donors, 0.987 to 0.502 for splice acceptors, and 0.971 to 0.577 for TATA promoters (Fig. 2b). The correct label for a shuffled sequence is poorly defined, though this result does support that ChatNT responses differ for the shuffled sequence compared to the original sequence. For protein models, providing the ESM3 embedding of a shuffled sequence to BioReason-Pro with GO-GPT and InterPro unperturbed results in minimal change in Fmax (0.855 vs. 0.856) across 14,102 human proteins. On a temporal holdout of proteins annotated after the checkpoint release, this is still observed (0.685 vs. 0.682). The shuffled sequence does influence the predicted GO term set for 46.8% of 14,102 proteins, with a mean Jaccard similarity of 0.89 to the GO term set predicted for the original sequence (Table S3). For Prot2Text-V2, BioBERT BERTScore F1 decreases by 0.177 with the name and taxon removed, showing a performance contribution from the ESM2 representation. Across five single-cell atlases, C2S-Scale 27B mean cell type accuracy falls from 0.446 to 0.351 after gene order shuffling and to 0.406 after resampling genes from all expressed genes (Fig. 2e). In Fig. 5 we further observe that removing DEGs from the cell sentence reduces C2S-Scale cell type annotation accuracy more than removing non-DEGs with similar expression. We next test whether model variants with higher benchmark performance also show greater perfor-mance contributions from the biological inputs evaluated in RQ1. For BioReason and BioReason-Pro, we compare the released SFT and RL checkpoints under the same perturbations of ZEvo2 and ZESM3 .For C2S-Scale, we compare the 2B and 27B checkpoints using the DEG removal experiment in Fig. 5. SFT and RL improve benchmark performance without greater performance contributions from 

ZEvo2 or ZESM3 . For BioReason, the SFT and RL checkpoints differ in disease prediction accuracy but show similarly limited performance contributions from ZEvo2 (Fig. 6a). With all biological text present, SFT accuracy is 0.823 with the original ZEvo2 and 0.814 when it is recomputed from shuffled DNA, whereas RL scores 0.847 and 0.847 under the same conditions. The same pattern is observed as we dropout the KEGG pathway and gene name, with both checkpoints remaining close to the identity line across the four conditions. Thus, the higher disease prediction accuracy of the BioReason RL checkpoint is not accompanied by a greater performance contribution from ZEvo2 .We observe the same pattern with BioReason-Pro with use of ZESM3 in impacting the Fmax perfor-mance (Fig. 6c). When GO-GPT and InterPro both present, RL increases Fmax from 0.829 for SFT to 0.855, while replacing ZESM3 with a representation recomputed from shuffled protein sequence changes Fmax from 0.829 to 0.833 for SFT and from 0.855 to 0.856 for RL. This limited performance contribution is also observed as InterPro and GO-GPT inputs are removed. Likewise, RL improves protein function prediction without increasing the performance contribution from ZESM3 . The same comparison across 42 post-training checkpoints that vary model size, SFT LoRA rank, RL LoRA rank and RL duration shows accuracy varying without a consistent increase in the advantage of the original ZEvo2 over the representation recomputed from shuffled DNA (Fig. 6b). Appendix C.1 reports the individual sweeps. 

DEGs contribute more to performance in the larger C2S-Scale model. C2S-Scale provides a contrasting relationship between benchmark performance and biological input contribution. Mean cell type accuracy with the unmodified Zcell increases from 0.366 for the 2B checkpoint to 0.446 for 27B while the accuracy decrease under DEG removal from the cell sentence also increases (Fig. 5). At 100% deletion of DEGs, the 2B model scores 0.140 after removing the strongest DEGs, and 0.363 after removing the same number of non-DEGs with similar expression, resulting in a DEG-specific difference of 0.223. The corresponding accuracies for 27B are 0.127 and 0.446, resulting in a larger difference of 0.319. Therefore, the DEG-specific effect is larger for 27B in all five atlases at full DEG removal. BioReason is trained with supervised fine-tuning on reason-ing traces that specify the base change in the first step, yet RQ3 shows that it rarely generates the correct base change. We therefore test whether explicit supervision of the edited bases improves their prediction and increases the contribu-tion of ZEvo2 to disease prediction performance. We replace the full reasoning trace with a short target specifying the reference and variant bases at the edited position while re-taining the disease answer (Appendix E). On 145 held-out queries, auxiliary supervision with 257-bp input windows yields edited base pair accuracy of 0.671 with intact DNA and 0.122 after shuffling. With 2,048-bp windows, the cor-responding accuracies are 0.531 and 0.099, compared with 0.080 for the base changes stated without auxiliary super-vision (Fig. 8b). Both auxiliary models also respond to sequence replacement in evidence conflicts (Fig. S4), while disease prediction accuracy changes little under shuffling (Fig. 8a). However, 135 of the 145 held-out queries contain genomes present in training. Pooling validation and held-out queries, edited base pair accuracy on 218 queries with previously seen genomes is 0.691 and 0.606 for the 257-bp and 2,048-bp models, respectively. On 72 queries with unseen genomes, accuracy falls to 0.148 and 0.106, compared with 0.111 for always predicting the most frequent training base pair (Table S10). Thus, the improvement is concentrated in previously seen genomes and increased sequence sensitivity on the original split does not establish reliable edited-base prediction on unseen genomes. 

Finding 4. Auxiliary supervision increases BioReason’s sequence sensitivity, but edited base prediction generalizes poorly to unseen genomes. Edited-base predictions respond to DNA shuffling and genome replacement, but accuracy improvements are concentrated to genomes present during training. Disease prediction accuracy also changes little when Evo2 representations are recomputed from shuffled DNA. 95 DISCUSSION 

Biological reasoning benchmarks can reward accurate answers without requiring models to interpret the biological representations they receive. When accompanying annotations already support the target, success does not establish that a model can extract complementary information from sequence or cellular inputs. Sensitivity to those inputs can occur but have limited overall performance benefit. Higher accuracy after post-training does not indicate a greater performance contribution from the biological input. Generated reasoning traces may also not accurately reflect inputs to the reasoning model. 

Limitations and future work. We evaluate six biological reasoning models on specific tasks and biological inputs, so the findings may not generalize to other architectures or biological modalities. Some analyses shuffle the sequence, which can move representations outside the distribution of natural sequences, although evidence conflicts built from unmodified inputs support the same conclusions. Linear probes from representations given to the reasoning model show that a target is predictable, but they do not show how the language model can use that representation. Future work could evaluate additional models and test training prompt variants within the same model while holding other training settings fixed. Reinforcement learning objectives that reward correct responses to changes in biological inputs, in addition to final accuracy, are another direction to evaluate. 

Conclusion. Biological reasoning models can achieve high benchmark performance with limited contributions from predictive biological inputs. Our results show that neither access to a predictive representation nor improved performance after SFT or RL ensures a performance contribution from that representation. The design and evaluation of biological reasoning models should consider the correct use of task-relevant biological inputs as an additional objective alongside predictive accuracy. ACKNOWLEDGMENTS

A.1.1 GENOMIC DATASETS AND EVALUATION SPLITS 

BioReason disease prediction task. The task uses the KEGG-derived dataset released with BioRea-son (Fallahpour et al., 2025) aggregated over all three splits (1,159 train, 146 test and 144 validation queries). The 1,449 queries cover 708 distinct reference/variant genome pairs, 186 distinct prompt texts and 37 disease labels. Each query comes with its prompt text, a reference sequence, a variant sequence and one gold disease. The prompt text has four variable fields: a Chromosome Number ,a Network Definition of the pathway in which the variant gene is marked with an aster-isk, Genes in the pathway with SYMBOL; description entries, and a query that names the variant gene and asks which disease the allele contributes to. The pathway definitions, pathway genes and disease labels are taken from KEGG. The dataset sequences for the reference and variant are encoded with Evo2. The disease label is the dataset’s answer string, and the 37 labels form the closed vocabulary used for scoring (Appendix A.2). All 1,449 queries are evaluated because every comparison in Figure 2a is paired with the same query but with the input shuffled. 

ChatNT tasks. ChatNT is evaluated on three of its own binary tasks from the released test split which contains three tasks: (1) splice donors (2,198 test queries, 1,098 Yes and 1,100 No, 600 bp), (2) splice acceptors (2,218 queries, 1,118 and 1,100, 600 bp) and (3) TATA promoters (621 queries, 332 and 289, 300 bp). From each task we sample up to 1,000 queries per class, giving 2,000, 2,000 and 578 queries (4,578 in total, balanced within task). A.1.2 PROTEIN DATASETS AND ANNOTATION PROCESSING 

Reviewed human proteome (BioReason-Pro). Proteins are obtained from UniProt with organism ID 9606 and filtered for reviewed entries. We keep only entries with curated GO ground truth, sequences of 120 to 1,024 residues (1,024 amino acids is the maximum sequence length for the GO-GPT encoder). This leaves 14,102 proteins, of which 14,019 have at least one InterPro entry. Ground truth is the GOA human annotation file (GAF 2.2, generated 2026-07-28), restricted to the evidence codes EXP, IDA, IPI, IMP, IGI, IEP, TAS and IC, with NOT qualifiers dropped and high-throughput codes excluded, over all three aspects. The file holds 16,991 annotated proteins with 149,820 annotations (8.8 per protein). 

Temporal holdout (BioReason-Pro). We use a cutoff of 2026-03-20, given by the day the BioReason-Pro preprint was posted. Proteins included in this holdout are reviewed UniProt entries of 120 to 1,024 residues added on or after the cutoff (706 entries). Entries whose GO cross-references carry only electronic evidence (615) are dropped, leaving 91 proteins, 90 of them with an InterPro entry. Labels are the UniProt GO cross-references with non-electronic evidence. The set spans several organisms (22 Drosophila , 18 Taxus chinensis , 9 Danio among others), and its proteins carry a median of 2 curated terms against 8.8 on the proteome. The level of Fmax on the holdout is therefore not comparable with the proteome, and we interpret only the within-holdout contrast between intact and shuffled input. 

Prot2Text-V2 test split. Prot2Text-V2 is evaluated on the official test split containing 4,203 proteins. The released pipeline truncates sequences to 1,021 residues. We exclude the 286 proteins longer than 1,021 residues so that a shuffled sequence is a permutation of the whole input, leaving 3,917 proteins for the perturbation experiment. B.3.1 GENOME -DEPENDENT DISEASE PREDICTION SUBSET 

Queries are grouped by the same prompt text (186 groups). A group is genome-dependent when it contains more than one distinct genome pair and more than one disease label. All other queries are genome-invariant, which means that every query with that text has the same label and a text-only predictor can score perfectly. The genome-dependent stratum has 165 queries in 14 text groups over 63 genomes and 12 labels, from six genes. With 126 train, 19 test and 20 validation queries. Within a group 118 queries carry the group’s strictly most frequent label, 41 carry a less frequent label, and 6 queries belong to one RET group whose two labels tie. 

Evo2 probes. We train linear probes on both the Evo2 representations as well as the projected Evo2 representations received by BioReason, ZEvo2 . In both, the reference and variant blocks are mean-pooled over their 2,048 positions and concatenated. The classifier is a multinomial logistic regression with L2 regularisation on standardised features, without class weighting. We use five folds, grouped by genome, so a held-out variant’s label must be inferred from other variants. 

Text-only predictor. The text-only predictor is fitted inside the same cross-validation loop as the probe. For each fold it assigns to a held-out query the most frequent gold label of that query’s text among the queries in the training fold. Averaged over the 10 fold assignments it scores 0.708 on the 165 queries. B.3.2 INTER PRO -CONTROLLED PROTEIN SUBSET AND FUNCTIONAL TARGETS 

We use the 540 proteins from the evidence conflict across the three properties with 199 proteins in 31 InterPro families for enzyme activity, 232 in 87 InterPro families for organelle targeting and 109 in 22 InterPro families for DNA binding, and 140 InterPro families in total. We use binary labels based on the presence of the GO term of the property GO:0003824 or GO:0008233 for enzyme activity, 

GO:0005739 or GO:0009507 for organelle targeting, and GO:0003677 for DNA binding. A negative label means the curated GO annotation lacks the term. GO NOT pairs are not used because their readout terms differ between pairs, so no single label is shared across them. We train the linear probe on predicting both the ESM3 representations and the projected repre-sentations that are used by BioReason-Pro. For each we use the mean-pooled representation over all residues. The classifier is a logistic regression with L2 regularisation at the library default on standardised features, fitted separately for the three properties, with five folds grouped by InterPro family. We score with AUROC within each InterPro family, and InterPro families are averaged with equal weight. B.4 REMOVING DIFFERENTIALLY EXPRESSED GENES FROM CELL SENTENCES 

DEGs are computed per atlas, from the log(1 + x) matrix with scanpy’s Wilcoxon rank-sum test of each annotated type against all other cells. A gene is a DEG of a type when its log 2 fold change is at least 1.0 and its Benjamini–Hochberg adjusted p-value is below 0.05. The fold change criterion is one-sided because the cell sentence is ranked by decreasing expression. DEGs are ranked by log 2

fold change times − log 10 of the adjusted p-value. For a given cell, its DEG set is the DEGs of its annotated type that occur in its own 1,000 gene sentence. The size of a cell’s DEG set varies by atlas: the median is 82, 66, 55, 136 and 97 genes in immune1, immune2, immune3, pancreas and lung. We remove proportions f ∈ { 0.10 , 0.25 , 0.50 , 0.75 , 1.00 } of the cell’s DEGs from the cell sentence. We compare four different ways of removing DEGs: (1) the highest ranked DEGs, (2) the weakest ranked DEGs (for f ≤ 0.75 because at f = 1 the set equals the set of strongest DEGs), (3) random 21 genes drawn uniformly from the cell’s own sentence, and (4) non-DEGs with similar expression given by the non-DEG of the same sentence with the nearest expression value in that cell to a DEG. Removed genes are deleted, not replaced, so the sentence shortens by the same number of genes under all four conditions. B.5 DISCUSSION OF TRAINING -TIME AVAILABILITY OF PREDICTIVE TEXT 

Here we compare the six models for training-time availability of predictive text. For BioReason, each disease prediction query provides the wild type and variant DNA sequence representations followed by the chromosome, pathway definition, gene list with descriptions and the query naming the gene. No masking, dropout or augmentation of the inputs is applied. A majority-vote table from the gene symbol named in the query to the disease, fitted on the train split, results in test set accuracy of 0.932 across the 91 genes which all occur in training. Therefore, the text inputs that are always present at training time is sufficient for the task. The BioReason-Pro training script uses InterPro and the GO-GPT prediction. No dropout of either input is used. ChatNT’s training queries give the task and the sequence representation. The query does not include details about the sequence, so no sequence-specific text can predict the label. Prot2Text-V2’s released data loader replaces the protein name and the taxon each by unknown with probability 0.8, independently, at every training step. CellWhisperer’s chat model is trained on conversations paired with a transcriptome representation, so the transcriptome representation is the input present in every prompt. C2S-Scale is trained to predict a cell type given only the cell sentence. Across the six models, the two models with training prompts that always contain answer-predictive text (BioReason and BioReason-Pro) show nearly unchanged performance under sequence shuffling and prefer the text in evidence conflicts. Conversely, the four models trained without such text (ChatNT, CellWhisperer, C2S-Scale) or with high dropout rates (Prot2Text-V2) show reduced performance under biological input perturbations and, where evaluated, prefer the sequence or cell source in conflicts. We report this as an observation only. The models differ in architecture, task, training data and scale, so this comparison cannot isolate the effect of training prompt content, and we do not test it with a controlled intervention.

E.2 AUXILIARY TARGET AND TRAINING 

Both windows of a query start at the same coordinates with 128 bp either side for the 257-bp condition and 1,024 bp before and 1,023 bp after for the 2,048-bp condition, so the edit sits at the same fixed offset for training and evaluation. For an insertion or deletion the two cuts agree before the edit and are shifted relative to each other after it. The auxiliary target replaces the reasoning trace with one line, Edit at i: ref X -> var Y (class) , where i is the offset of the edit, X and Y are the reference and variant bases there, and the class is substitution, insertion, deletion, or multi-base. The control keeps the benchmark’s reasoning trace, which has a median of 2,197 characters and names the substituted bases in 865 of the 1,159 training queries. The bases are available only from the input DNA representations. One training query of the 257-bp run is
